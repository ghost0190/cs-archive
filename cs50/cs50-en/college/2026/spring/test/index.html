The test will cover concepts from Weeks 0 through 7 (and Problem Sets 0 through 7). Among the test’s aims is to assess your newfound comfort with the course’s material and your ability to apply the course’s lessons to familiar and unfamiliar problems.

The test is closed-book, but you may utilize during the test one two-sided page of notes (Letter- or A4-sized, typed or written), a pencil or pen, blank paper, and a laptop, nothing else.

In other words, you may not, during the test:

  • ask questions of anyone; except in the case of technical difficulty, you may email heads@cs50.harvard.edu.
  • browse or search the internet,
  • review any materials other than your one page of notes,
  • use any software (e.g., cs50.dev or VS Code itself),
  • use any artificial intelligence (e.g., ChatGPT, Claude, Copilot, Gemini, et al. or cs50.ai),
  • provide help to anyone, or
  • receive or solicit help from anyone other than the course’s heads.

Take care to review the course’s policy on academic honesty in its entirety. Note particularly, but not only, that

  • looking at another individual’s work during the test is not reasonable and
  • turning to humans (besides the course’s heads) for help or receiving help from humans (besides the course’s heads) during the test is not reasonable.

Test Format

The test will be adminstered primarily through Canvas, using Proctorio, which is remote-proctoring software that works within your web browser, monitoring your video and screen activity during the test. To use Proctorio, you’ll need to install a browser extension, which is compatible with Brave, Edge, Google Chrome, and Opera, but not Safari. The extension can be uninstalled once the test is complete. You will have exactly three (3) hours to complete the test; you must submit within 3 hours of starting. The test itself is intended to take no more than 3 hours. You may start anytime after the test’s release, and you may submit no later than its deadline:

How to Prepare

Ultimately, how best to prepare depends on how you learn best, but allow us to recommend some of the following resources to help you study.

  1. Attempt the practice problems and, only after you’ve attempted each of their questions, review their sample solutions.
  2. Review each week’s notes.
  3. Review each week’s source code, if any.
  4. Review each week’s slides.
  5. Review each week’s shorts, if any.
  6. Review problem sets’ specifications, sample solutions, and, if any, distribution code.
  7. Review problem set form questions.
  8. Review each lecture’s video.

Allow us to also recommend some study strategies. Overall, preparation should focus on understanding concepts and applying them, rather than memorizing isolated facts.

  • Prepare your note sheet, per the content overview!
  • Create a mind map, a visual diagram, listing concepts from the course and how they are connected. Brain dump everything you know about that topic, then review course materials to see what you missed or what you were unsure about.
  • Teach your own test review to another person, and review what you had trouble explaining.
  • Write your own (or ask the CS50 duck for) practice questions and solve them.

Content Overview

Here are some, but not all, of the key things you should understand or know how to do, separated by week.

Across Weeks

  • Understand how data is represented in computers and recognize the tradeoffs and limitations that arise from those representations.
  • Read and write code in C and Python.
  • Translate between pseudocode and working code.
  • Identify bugs and undefined behavior in programs.
  • Compare design choices and justify tradeoffs (efficiency, memory, flexibility, etc.).

Week 0: Scratch

  • Explain what algorithms are.
  • Apply abstraction to break problems into smaller components.

Week 1: C

  • Write, compile, and run C programs.
  • Work with core programming constructs (variables, loops, conditionals, functions, etc.).
  • Understand integer limits and overflow behavior.
  • Understand floating-point imprecision.

Week 2: Arrays

  • Work with arrays and understand strings as char arrays.
  • Use string and character libraries (strlen, toupper, etc.).
  • Use command-line arguments (argc, argv).

Week 3: Algorithms

  • Compare searching algorithms (linear vs. binary search).
  • Understand Big-O, Ω, and Θ notations.
  • Compare sorting algorithms (bubble sort, selection sort, merge sort) and their runtimes.
  • Use and understand structs.
  • Apply recursion (base case and recursive case).

Week 4: Memory

  • Understand memory addresses and hexadecimal notation.
  • Use pointers (*) and dereferencing (&).
  • Use dynamic memory (malloc, free) and identify errors (e.g., leaks, invalid access).
  • Distinguish pass-by-value vs. pass-by-reference.
  • Use file I/O (fopen, fread, fwrite, fclose, etc.).
  • Identify and debug memory issues.

Week 5: Data Structures

  • Compare arrays vs. linked lists (tradeoffs in access, insertion, deletion).
  • Create a linked list, insert nodes, and traverse linked lists.
  • Understand stacks, queues, trees, and tries, including tradeoffs and runtimes.
  • Explain benefits of hash tables and hash functions.

Week 6: Python

  • Write Python programs using variables, functions, conditionals and loops.
  • Work with lists and dictionaries.
  • Use file I/O (open, read/write, CSV handling).
  • Use command-line arguments (sys.argv) and exit codes.

Week 7: SQL

  • Understand relational databases and database design tradeoffs.
  • Write SELECT queries with filtering (WHERE, LIKE), sorting (ORDER BY), and limits.
  • Use aggregation functions (COUNT, AVG, DISTINCT, GROUP BY).
  • Integrate SQL with Python programs (db.execute).
  • Recognize issues like race conditions and SQL injection.

How to Take the Test, when the time comes

  1. Open the CS50 Test on Canvas.

  2. Ensure you have the Proctorio Browser Extension installed.
  3. Read the Test instructions thoroughly and ensure you understand all test instructions and course’s honesty policy before proceeding.
  4. Once you begin the test, the 3-hour timer will begin. The test will automatically submit after 3 hours. If you start with less than 3 hours before the test deadline, the test will submit automatically at the deadline, even if that means you have less than 3 hours to work on it.

If you run into any trouble with the steps above, email heads@cs50.harvard.edu!
