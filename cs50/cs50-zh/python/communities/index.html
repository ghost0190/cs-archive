社区

So that students can connect with classmates via platforms on which they’re already spending (too much!) 时间, CS50 has official 社区 on Discord, Ed, Facebook, Gitter, Instagram, LinkedIn, Quora, Reddit, Slack, Snapchat, SoundCloud, TikTok, X, and YouTube.

If not already a user of any of those, allow us to suggest that you start with Ed!
