项目 3: Events

When to Do It

By 2026-12-31T23:59:00+00:00.

What to Do

Visit scratch.mit.edu and sign in to your account. Click the “Create” button to create a new 项目.

Your 作业 is to create an interactive Scratch 项目 that lets the user press the arrow keys to control a sprite. Your 项目 should include:

  • At least two events.

Once finished with your 项目, select File > Save now one last 时间. Then select File > Save to your computer and keep that file (with file extension .sb3) so that you can 提交 it. If prompted by your computer to 打开 or Save the file, be sure to Save it.

如何提交

This step assumes that you’ve downloaded your Scratch 项目 as a file whose 姓名 ends in .sb3. And this step also assumes that you’ve signed up for a GitHub account, per the above form.

  1. Visit this link, log in with your GitHub account, and click Authorize cs50.
  2. Check the box indicating that you’d like to grant 课程 工作人员 access to your submissions, and click Join 课程.
  3. Go to 提交.cs50.io/upload/cs50/problems/2024/scratch/events.
  4. Click “Choose File” and choose your .sb3 file. Click 提交.

If you encounter the error “No files in this directory are expected by cs50/problems/2024/scratch/events”, please make sure your scratch 项目 file 姓名 indeed ends with .sb3!

That’s it! Once your submission uploads, you should be redirected to your submission page. Click the submission link and then the check50 link to see which requirements your 项目 met. You are 欢迎 to resubmit as many times as you’d like (before the 截止时间)! 笔记 that if you upload a file whose size is larger than 10MB (which is quite large for a Scratch 项目) check50 五月 struggle to process it. Best to make sure your file is smaller than that limit.

To view your current progress in the 课程, visit the 课程 成绩册 at cs50.me/cs50s!
