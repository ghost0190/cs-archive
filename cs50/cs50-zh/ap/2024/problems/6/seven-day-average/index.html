Seven Day Averages

Learning Goals

  • Work with 直播 data
  • Get practice with CSV files and csv.DictReader

背景

In this program, you will be using a 新内容 York Times repository of 直播, cumulative COVID data to calculate 新内容 daily cases, create a 7-day average, and compare this 周’s average to the 上一页 周.

实现细节

The distribution code for this 问题 uses the Python requests library to access the 新内容 York Times data stored in an accessible GitHub repository. 这是 stored as a CSV file. The program then uses DictReader to 阅读 the CSV file. It then creates a states list to use selected states for calculations.

You will be completing two functions, calculate and comparative_averages.

calculate

In calculate, you’ll be creating a dictionary, new_cases, which will keep track of 14 days of 新内容 COVID cases for each state. Keys in this dict will be the names of states, and the values for each of those keys will be the most recent 14 days of 新内容 cases. Since the data from the 新内容 York Times is cumulative, each day’s 新内容 cases must be calculated by subtracting the 上一页 day’s cases. To do this, you 五月 want to create a second dictionary, previous_cases, that keeps track of each day’s 新内容 cases as it’s calculated.

  • 提示

Your calculate function should ultimately return the new_cases dictionary.

comparative_averages

Since your new_cases dictionary is passed to this function, you can calculate this 周’s 7-day average by summing up the last 7 elements in the list for a selected state, then dividing this by 7. You can create a 7-day average for the 上一页 周 by doing the same with the first 7 elements in that same list.

  • 提示

You can then calculate the percent increase or decrease, by taking the difference of the two 7-day averages and dividing by last 周’s average.
