信用卡

Implement a program that determines whether a provided 信用卡 card number is valid according to Luhn’s algorithm.

$ python credit.py
Number: 378282246310005
AMEX

入门

Log into code.cs50.io, click on your terminal window, and execute cd by itself. You should find that your terminal window’s prompt resembles the below:

$

下一页 execute

wget https://cdn.cs50.net/2022/fall/psets/6/sentimental-credit.zip

in order to 下载 a ZIP called sentimental-credit.zip into your codespace.

Then execute

unzip sentimental-credit.zip

to create a folder called sentimental-credit. You no longer need the ZIP file, so you can execute

rm sentimental-credit.zip

and respond with “y” followed by Enter 在 the prompt to remove the ZIP file you downloaded.

Now type

cd sentimental-credit

followed by Enter to move yourself into (i.e., 打开) that directory. Your prompt should now resemble the below.

sentimental-credit/ $

Execute ls by itself, and you should see credit.py. If you run into any trouble, follow these same steps again and see if you can determine where you went wrong!

规格说明

  • In credit.py, write a program that prompts the user for a 信用卡 card number and then reports (via print) whether it is a valid American Express, MasterCard, or Visa card number, exactly as you did in 问题集 1, except that your program this 时间 should be written in Python.
  • So that we can automate some tests of your code, we ask that your program’s last line of output be AMEX\n or MASTERCARD\n or VISA\n or INVALID\n, nothing 更多, nothing 较少.
  • For simplicity, you 五月 assume that the user’s input will be entirely numeric (i.e., devoid of hyphens, as might be printed on an actual card).
  • Best to use get_int or get_string from CS50’s library to get users’ input, depending on how you to decide to implement this one.

Usage

Your program should behave per the 示例 below.

$ python credit.py
Number: 378282246310005
AMEX

提示

  • It’s possible to use regular expressions to validate user input. You might use Python’s re module, for 示例, to check whether the user’s input is indeed a sequence of digits of the correct length.

测试

While check50 is available for this 问题, you’re encouraged to first test your code on your own for each of the following.

  • Run your program as python credit.py, and wait for a prompt for input. Type in 378282246310005 and press enter. Your program should output AMEX.
  • Run your program as python credit.py, and wait for a prompt for input. Type in 371449635398431 and press enter. Your program should output AMEX.
  • Run your program as python credit.py, and wait for a prompt for input. Type in 5555555555554444 and press enter. Your program should output MASTERCARD.
  • Run your program as python credit.py, and wait for a prompt for input. Type in 5105105105105100 and press enter. Your program should output MASTERCARD.
  • Run your program as python credit.py, and wait for a prompt for input. Type in 4111111111111111 and press enter. Your program should output VISA.
  • Run your program as python credit.py, and wait for a prompt for input. Type in 4012888888881881 and press enter. Your program should output VISA.
  • Run your program as python credit.py, and wait for a prompt for input. Type in 1234567890 and press enter. Your program should output INVALID.

Execute the below to evaluate the correctness of your code using check50. But be sure to compile and test it yourself as well!

check50 cs50/problems/2023/x/sentimental/credit

Execute the below to evaluate the style of your code using style50.

style50 credit.py

submit50 cs50/problems/2023/x/sentimental/credit
