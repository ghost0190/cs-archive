Web Development

  • Recall that we discussed HTTP in the context of 互联网 technologies and HTML in the context of web development. What’s the difference between HTTP and HTML?

  • Recall that we discussed both HTML and CSS in the context of web development. What’s the difference between HTML and CSS?

  • For this challenge, you might find it helpful to skim or 搜索 http://htmldog.com/guides/HTML/ and http://htmldog.com/guides/CSS/, which build upon concepts from 讲座.

    Visit sandbox.cs50.io/?window=browser&window=terminal&window=editor&file=index.HTML&file=styles.CSS, logging in via GitHub if prompted, to create a CS50 Sandbox (a small web-based development environment) containing files called index.html and styles.css, both initially empty, pre-created for you.

    Now let’s have you make an actual website with multiple pages. To test that your website is behaving as expected, in the terminal window 在 the bottom you can type http-server, which will then allow you to use the embedded browser viewer on the right to view your page.

    We’ll leave its design largely up to you, subject only to the following requirements:

    1. Your website’s main page should 直播 in index.html, since most web servers serve up index.html by default, in the absence of an explicit file 姓名 in a URL.
    2. Your website must include a least one other page with a similar amount of content (with any filename, so long as it ends in .HTML), and your website’s main page (i.e., index.html) must somehow link to that page. You can click the little folder icon 在 the window’s top-left to 打开 the file tree, then the “+” to add additional files or folders in your Sandbox.
    3. Your website should use relative, and not absolute, links.
    4. Your website must include 在 least one image. 笔记 that the above instructions for creating 新内容 files also allow you to upload files, though you 五月 also use images already on the 互联网.
    5. Your website must be stylized with 在 least some CSS, which must 直播 in styles.CSS (an “external stylesheet”), just as we saw (briefly) in css4.HTML. Your stylesheet should utilize 在 least a handful of CSS properties.
    6. Your website should be 更多 complex than those from class (but much 较少 complex than Harvard’s 首页 page!). As such, your website should probably use several dozen HTML tags overall.

    Alright, make us proud!

    When done, click “Share”. Take care not to 关闭 your sandbox before making 笔记 of its URL, lest you lose work!

    To view (and thus test!) your web page, remember to run http-server in your sandbox’s terminal window, and then reload the embedded browser via the icon to the left of “localhost:8080”.
