许可协议

练习题

If you want some extra practice in addition to the 问题集 for a 周, you can choose from these 练习题. 笔记 that,in many cases, the 练习 can be harder than the 问题集 themselves!

第 1 周

These problems assume that you have already set up your CS50 Codespace. Be sure to complete that before attempting these problems.

  • 调试, for becoming familiar with C syntax and debugging programs.
  • Half, for practice creating a function.
  • 素数, for practice using for loops.

第 2 周

  • Hours, for practice with arrays, passing arrays as parameters to a function, integer division and type casting.
  • N0 V0w3ls, for practice with strings, command-line arguments, and writing an entire program from scratch.
  • Password, for practice iterating through a string, using the ctype.h library, and using Boolean variables.

第 3 周

  • Recursive atoi, for practice creating recursive functions.
  • Average Temperatures, for practice working with structs and sorting 算法.
  • Max, for practice passing arrays to functions and finding maximum values.
  • Snackbar, for practice using structs and writing a linear 搜索 algorithm.

第 4 周

  • Bottom Up, for practice working with images and metadata.
  • 许可协议, for practice working with files and file 指针.

第 5 周

  • Trie, for introducing 更多 complex 数据结构 and working with tries.

第 6 周

  • Bank, from CS50’s Introduction to 编程 with Python, for practice with strs.
  • Frank, Ian and Glen’s Letters, from CS50’s Introduction to 编程 with Python, for practice with libraries and command-line arguments.
  • Jar, from CS50’s Introduction to 编程 with Python, for an introduction to classes and object-oriented 编程, if feeling 更多 comfortable.
  • Seven Day Average, for practice with requests, dicts, and data, if feeling 更多 comfortable.
  • Taqueria, from CS50’s Introduction to 编程 with Python, for practice with dicts and try-except blocks.

第 7 周

  • Favorites for practice using SELECT and UPDATE keywords.
  • Hall of Prophecy for practice refactoring a database, using CREATE.

第 8 周

  • Radio Shack Redo, for practice with Bootstrap (and some web development history!)

第 9 周

  • 你好, Flask, for practice writing a Flask application from scratch.
