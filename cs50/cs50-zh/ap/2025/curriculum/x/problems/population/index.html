Population Growth

Determine how long it takes for a population to reach a particular size.

$ ./population
Start size: 100
End size: 200
Years: 9

背景

Say we have a population of n llamas. Each year, n / 3 新内容 llamas are born, and n / 4 llamas pass away.

For 示例, if we were to 开始 with n = 1200 llamas, then in the first year, 1200 / 3 = 400 新内容 llamas would be born and 1200 / 4 = 300 llamas would pass away. 在 the 结束 of that year, we would have 1200 + 400 - 300 = 1300 llamas.

To try another 示例, if we were to 开始 with n = 1000 llamas, 在 the 结束 of the year, we would have 1000 / 3 = 333.33 新内容 llamas. We can’t have a decimal portion of a llama, though, so we’ll truncate the decimal to get 333 新内容 llamas born. 1000 / 4 = 250 llamas will pass away, so we’ll 结束 up with a total of 1000 + 333 - 250 = 1083 llamas 在 the 结束 of the year.

实现细节

Complete the implementation of population.c, such that it calculates the number of years 必需 for the population to grow from the 开始 size to the 结束 size.

  • Your program should first prompt the user for a starting population size.
    • If the user enters a number 较少 than 9 (the minimum allowed population size), the user should be re-prompted to enter a starting population size until they enter a number that is greater than or equal to 9. (If we 开始 with fewer than 9 llamas, the population of llamas will quickly become stagnant!)
  • Your program should then prompt the user for an ending population size.
    • If the user enters a number 较少 than the starting population size, the user should be re-prompted to enter an ending population size until they enter a number that is greater than or equal to the starting population size. (After all, we want the population of llamas to grow!)
  • Your program should then calculate the (integer) number of years 必需 for the population to reach 在 least the size of the 结束 value.
  • Finally, your program should print the number of years 必需 for the llama population to reach that 结束 size, as by printing to the terminal Years: n, where n is the number of years.

提示

  • If you want to repeatedly re-prompt the user for the value of a variable until some condition is met, you might want to use a do ... while loop. For 示例, recall the following code from 讲座, which prompts the user repeatedly until they enter a positive integer.

      int n;
  do
  {
      n = get_int("Positive Integer: ");
  }
  while (n < 1);

    How might you adapt this code to ensure a 开始 size of 在 least 9, and an 结束 size of 在 least the 开始 size?

  • To declare a 新内容 variable, be sure to specify its data type, a 姓名 for the variable, and (optionally) what its initial value should be.
    • For 示例, you might want to create a variable to keep track of how many years have passed.

  • To calculate how many years it will take for the population to reach the 结束 size, another loop might be helpful! Inside the loop, you’ll likely want to update the population size according to the formula in the 背景, and update the number of years that have passed.

  • To print an integer n to the terminal, recall that you can use a line of code like

      printf("The number is %i\n", n);

    to specify that the variable n should fill in for the placeholder %i.
