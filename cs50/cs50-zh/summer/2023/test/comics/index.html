Not only has code.cs50.io enabled you to use VS Code in the cloud, without installing it on your own Mac or PC, it has also had clang, python, sqlite3, http-server, and flask pre-configured for you. While you’re 欢迎 to continue using your codespace after term’s end, let’s also prepare you to write, at least, Python on your own Mac or PC!

  1. (1 point.) Complete each of the steps below. You might encounter some technical difficulty along the way, but that’s why this problem is at term’s end rather than start!

    1. 下载 VS Code from code.visualstudio.com and install it on your own Mac or PC, per these instructions. If you have a Chromebook, though, you 五月 skip this problem or try these instructions instead.

    2. 下载 the latest version of Python from python.org/下载 and install it on your own Mac or PC.

    3. Launch VS Code on your own Mac or PC and create a new file called hello.py containing just the below:

      print("hello, world")

      Save the file and execute the below in VS Code’s terminal window. You might need to cd first to the directory with hello.py.

      python hello.py

      If the command is not found, try python3 instead of python, else you might also find 搜索 results like google.com/搜索?q=add+python+to+path of help. Alternatively, for this problem and this problem only, you are 欢迎 to ask another human for help.

    4. As soon as “你好, 世界” prints as expected, take a screenshot (showing your code and your terminal window) and 提交 it as your 答案 to this problem.
