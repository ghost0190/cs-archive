排序

Problem to Solve

Recall from 讲座 that we saw a few 算法 for sorting a sequence of numbers: 选择排序, 冒泡排序, and 归并排序.

  • 选择排序 iterates through the unsorted portions of a list, selecting the smallest element each 时间 and moving it to its correct 地点.
  • 冒泡排序 compares pairs of adjacent values one at a 时间 and swaps them if they are in the incorrect order. This continues until the list is sorted.
  • 归并排序 recursively divides the list into two repeatedly and then merges the smaller lists 返回 into a larger one in the correct order.

In this problem, you’ll analyze three (compiled!) sorting programs to determine which 算法 they use. In a file called answers.txt in a folder called sort, record your 答案, along with an explanation for each program, by filling in the blanks marked TODO.

Distribution Code

For this problem, you’ll need some “distribution code”—that is, code written by CS50’s 工作人员. Provided to you are three already-compiled C programs, sort1, sort2, and sort3, as well as several .txt files for input and another file, answers.txt, in which to write your 答案. Each of sort1, sort2, and sort3 implements a different sorting algorithm: 选择排序, 冒泡排序, or 归并排序 (though not necessarily in that order!). Your task is to determine which sorting algorithm is used by each file. Start by downloading these files.

打开 VS Code.

Start by clicking inside your terminal window, then execute cd by itself. You should find that its “prompt” resembles the below.

$

Click inside of that terminal window and then execute

wget https://cdn.cs50.net/2023/spring/psets/3/sort.zip

followed by Enter in order to 下载 a ZIP called sort.zip in your codespace. Take care not to overlook the space between wget and the following URL, or any other character for that matter!

Now execute

unzip sort.zip

to create a folder called sort. You no longer need the ZIP file, so you can execute

rm sort.zip

and respond with “y” followed by Enter at the prompt to remove the ZIP file you downloaded.

提示

Explore the .txt files
  • Multiple .txt files are provided to you. These files contain n lines of values, either reversed, shuffled, or sorted.
    • For 示例, reversed10000.txt contains 10000 lines of numbers that are reversed from 10000, while random100000.txt contains 100000 lines of numbers that are in random order.
  • The different types of .txt files 五月 help you determine which 排序 is which. Consider how each algorithm performs with an already sorted list. How 关于 a reversed list? Or shuffled list? It 五月 help to work through a smaller list of each type and walk through each sorting process.
时间 each 排序 with different inputs
  • To run the sorts on the text files, in the terminal, run ./[program_name] [text_file.txt]. Make sure you have made use of cd to move into the sort directory!
    • For 示例, to 排序 reversed10000.txt with sort1, run ./sort1 reversed10000.txt.
  • You 五月 find it helpful to 时间 your sorts. To do so, run time ./[sort_file] [text_file.txt].
    • For 示例, you could run time ./sort1 reversed10000.txt to run sort1 on 10,000 reversed numbers. At the end of your terminal’s output, you can look at the real 时间 to see how much 时间 actually elapsed while running the program.
