搜索

讲座 1 and 2 are not 必需 to complete this 项目, but 五月 prove helpful if you’re struggling to 提交 it, since they teach Git, among other topics!

Design a front-end for Google 搜索, Google Image 搜索, and Google Advanced 搜索.

背景

Recall from 讲座 that we can create an HTML form using a <form> tag and can add <input> tags to create input fields for that form. Later in the 课程, we’ll see how to write web applications that can accept form data as input. For this 项目, we’ll write forms that send data to an existing web server: in this case, Google’s.

When you perform a Google 搜索, as by typing in a query into Google’s 主页 and clicking the “Google 搜索” button, how does that query work? Let’s try to find out.

Navigate to google.com, type in a query like “Harvard” into the 搜索 field, and click the “Google 搜索” button.

As you probably expected, you should see Google 搜索 results for “Harvard.” But now, take a look at the URL. It should begin with https://www.google.com/search, the route on Google’s website that allows for searching. But following the route is a ?, followed by some additional information.

Those additional pieces of information in the URL are known as a query string. The query string consists of a sequence of GET parameters, where each parameter has a 姓名 and a value. Query strings are generally formatted as

field1=value1&field2=value2&field3=value3...

where an = separates the 姓名 of the parameter from its value, and the & symbol separates parameters from one another. These parameters are a way for forms to 提交 information to a web server, by encoding the form data in the URL.

Take a look at the URL for your Google 搜索 results page. It seems there are quite a few parameters that Google is using. Look through the URL (it 五月 be helpful to copy/paste it into a text editor), and see if you can find any mention of “Harvard,” our query.

If you look through the URL, you should see that one of the GET parameters in the URL is q=Harvard. This suggests that the 姓名 for the parameter corresponding to a Google 搜索 is q (likely short for “query”).

It turns out that, while the other parameters provide useful data to Google, only the q parameter is 必需 to perform a 搜索. You can test this for yourself by visiting https://www.google.com/search?q=Harvard, deleting all the other parameters. You should see the same Google results!

Using this information, we can actually re-implement a front end for Google’s 主页. Paste the below into an HTML file called index.html, and 打开 it in a browser. You can alternatively 下载 the index.html file directly from the “入门” 小组课 below.

<!DOCTYPE html>
<html lang="en">
    <head>
        <title>Search</title>
    </head>
    <body>
        <form action="https://www.google.com/search">
            <input type="text" name="q">
            <input type="submit" value="Google Search">
        </form>
    </body>
</html>

When you 打开 this page in a browser, you should see a (very simple) HTML form. Type in a 搜索 query like “Harvard” and click “Google 搜索”, and you should be taken to Google’s 搜索 results page!

How did that work? In this case, the action attribute on the form told the browser that when the form is submitted, the data should be sent to https://www.google.com/search. And by adding an input field to the form whose name attribute was q, whatever the user types into that input field is included as a GET parameter in the URL.

Your task in this 项目 is to expand on this site, creating your own front end for Google 搜索, as by exploring Google’s interface to identify what GET parameters it expects and adding the necessary HTML and CSS to your website.

入门

  • 下载 the distribution code from https://cdn.cs50.net/web/2020/春季/项目/0/搜索.zip and unzip it. You can skip this step if you manually created the index.html file by following the steps outlined in the “背景” 小组课 above.

规格说明

Your website must meet the following requirements:

  • Pages. Your website should have at least three pages: one for regular Google 搜索 (which must be called index.html), one for Google Image 搜索, and one for Google Advanced 搜索.
    • On the Google 搜索 page, there should be links in the upper-right of the page to go to Image 搜索 or Advanced 搜索. On each of the other two pages, there should be a link in the upper-right to go 返回 to Google 搜索.
  • Text 搜索. On the Google 搜索 page, the user should be able to type in a query, click “Google 搜索”, and be taken to the Google 搜索 results for that page.
    • Like Google’s own, your 搜索 bar should be centered with rounded corners. The 搜索 button should also be centered, and should be beneath the 搜索 bar.
  • Image 搜索. On the Google Image 搜索 page, the user should be able to type in a query, click a 搜索 button, and be taken to the Google Image 搜索 results for that page.
  • Advanced 搜索. On the Google Advanced 搜索 page, the user should be able to provide input for the following four fields (taken from Google’s own advanced 搜索 options)
    • Find pages with… “all these words:”
    • Find pages with… “this exact word or phrase:”
    • Find pages with… “any of these words:”
    • Find pages with… “none of these words:”
  • Visual Consistency. Like Google’s own Advanced 搜索 page, the four options should be stacked vertically, and all of the text fields should be left aligned.
    • Consistent with Google’s own CSS, the “Advanced 搜索” button should be blue with white text.
    • When the “Advanced 搜索” button is clicked, the user should be taken to the 搜索 results page for their given query.
  • Lucky. Add an “I’m Feeling Lucky” button to the main Google 搜索 page. Consistent with Google’s own behavior, clicking this link should take users directly to the first Google 搜索 result for the query, bypassing the normal results page.
    • You 五月 encounter a redirect notice when using the “I’m Feeling Lucky” button. Not to worry! This is an expected consequence of a 安全 feature implemented by Google.
  • Aesthetics. The CSS you write should resemble Google’s own aesthetics.

提示

  • To determine what the parameter names should be, you’re 欢迎 to experiment with making Google searches, and looking at the resulting URL. It 五月 also be helpful to 打开 the “Network” inspector (accessible in Google Chrome by choosing View -> Developer -> Developer 工具) to view details 关于 requests your browser makes to Google.
    • Any <input> element (whether its type is text, submit, number, or something else entirely) can have name and value attributes that will become GET parameters when a form is submitted.
    • You 五月 also find it helpful to look at Google’s own HTML to 答案 these 问题. In most browsers, you can control-click or right-click on a page and choose “View Page Source” to view the page’s underlying HTML.
  • To include an input field in a form that users cannot see or modify, you can use a “hidden” input field.
