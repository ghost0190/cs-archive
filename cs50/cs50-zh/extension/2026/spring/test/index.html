The test will be administered through Canvas, using Proctorio, which is remote-proctoring software that works within your web browser, monitoring your 视频 and screen activity during the test. To use Proctorio, you’ll need to install a browser extension, which is compatible with Brave, Edge, Google Chrome, and Opera, but not Safari. The extension can be uninstalled once the test is complete. You will have exactly three (3) 时间 to complete the test; you must 提交 within 3 时间 of starting. The test itself is intended to take no 更多 than three (3) 时间. You 五月 开始 anytime after the test’s release, and you 五月 提交 no later than its 截止时间:

Content Overview

Here are some, but not all, of the key things you should understand or know how to do, separated by 周.

Across 周次

  • Understand how data is represented in computers and recognize the tradeoffs and limitations that arise from those representations.
  • 阅读 and write code in C and Python.
  • Translate between pseudocode and working code.
  • Identify bugs and undefined behavior in programs.
  • Compare design choices and justify tradeoffs (efficiency, 内存, flexibility, etc.).

第 0 周: Scratch

  • Explain what 算法 are.
  • Apply abstraction to break 问题 into smaller components.

第 1 周: C

  • Write, compile, and run C programs.
  • Work with core 编程 constructs (variables, loops, conditionals, functions, etc.).
  • Understand integer limits and overflow behavior.
  • Understand floating-point imprecision.

第 2 周: Arrays

  • Work with arrays and understand strings as char arrays.
  • Use string and character libraries (strlen, toupper, etc.).
  • Use command-line arguments (argc, argv).

第 3 周: 算法

  • Compare searching 算法 (linear vs. 二分搜索).
  • Understand Big-O, Ω, and Θ notations.
  • Compare sorting 算法 (冒泡排序, 选择排序, 归并排序) and their runtimes.
  • Use and understand structs.
  • Apply 递归 (base case and recursive case).

第 4 周: 内存

  • Understand 内存 addresses and hexadecimal notation.
  • Use 指针 (*) and dereferencing (&).
  • Use dynamic 内存 (malloc, free) and identify errors (e.g., leaks, invalid access).
  • Distinguish pass-by-value vs. pass-by-reference.
  • Use file I/O (fopen, fread, fwrite, fclose, etc.).
  • Identify and 调试 内存 issues.

第 5 周: 数据结构

  • Compare arrays vs. 链表 (tradeoffs in access, insertion, deletion).
  • Create a linked list, insert nodes, and traverse 链表.
  • Understand stacks, queues, trees, and tries, including tradeoffs and runtimes.
  • Explain benefits of 哈希表 and hash functions.

第 6 周: Python

  • Write Python programs using variables, functions, conditionals and loops.
  • Work with lists and dictionaries.
  • Use file I/O (打开, 阅读/write, CSV handling).
  • Use command-line arguments (sys.argv) and exit codes.

第 7 周: SQL

  • Understand relational 数据库 and database design tradeoffs.
  • Write SELECT queries with filtering (WHERE, LIKE), sorting (ORDER BY), and limits.
  • Use aggregation functions (COUNT, AVG, DISTINCT, GROUP BY).
  • Integrate SQL with Python programs (db.execute).
  • Recognize issues like race conditions and SQL injection.
