Outline

Outlined below is the 课程’s subject matter, organized by 周, each subtitled per to the context in which its topics are introduced.

第 0 周 Scratch

计算机科学. Computational Thinking. Problem Solving: Inputs, Outputs. Representation: Unary, Binary, Decimal, ASCII, Unicode, RGB. Abstraction. 算法. Running Times. Pseudocode. Scratch: Functions, Arguments, Return Values; Variables; Boolean Expressions, Conditionals; Loops; Events; Threads.

第 1 周 C

C. 源代码. Machine Code. Compiler. Correctness, Design, Style. Visual Studio Code. Syntax Highlighting. Escape Sequences. Header Files. Libraries. Manual Pages. Types. Conditionals. Variables. Loops. Linux. Graphical User Interface (GUI). Command-Line Interface (CLI). Constants. Comments. Pseudocode. Operators. Integer Overflow. Floating-Point Imprecision.

第 2 周 Arrays

Preprocessing. Compiling. Assembling. Linking. Debugging. Arrays. Strings. Command-Line Arguments. 密码学.

第 3 周 算法

Searching: Linear 搜索, 二分搜索. Sorting: 冒泡排序, 选择排序, 归并排序. Asymptotic Notation: \(O\), \(\Omega\), \(\Theta\). 递归.

第 4 周 内存

指针. Segmentation Faults. 动态内存分配. Stack. Heap. Buffer Overflow. File I/O. Images.

第 5 周 数据结构

Abstract Data Types. Queues, Stacks. 链表. Trees, 二分搜索 Trees. 哈希表. Tries.

第 6 周 Python

Python: Functions, Arguments, Return Values; Variables; Boolean Expressions, Conditionals; Loops. Modules, Packages.

第 7 周 SQL

SQL: Tables; Types; Statements; Constraints; Indexes; Keywords, Functions; Transactions. Race Conditions. SQL Injection Attacks.

第 8 周 HTML, CSS, JavaScript

互联网: Routers; TCP/IP; DNS. HTTP: URLs, GET, POST. HTML: Tags; Attributes. Servers. Regular Expressions. CSS: Properties; Selectors. Frameworks. JavaScript: Variables; Conditionals; Loops. Events.

第 9 周 Flask

Flask. Route. Decorators. Requests, Responses. Sessions. Cookies.

第 10 周 人工智能

Prompt Engineering. System Prompt. User Prompt. Generative 人工智能. 人工智能. Decision Trees. Minimax. 机器学习. Reinforcement Learning. Explore vs. Exploit. Deep Learning. Neural Networks. Large Language Models. Transformer Architecture. Hallucinations.

周 11 The End

Fun. Games.

Quantitative Reasoning with Data

笔记 that you must take CS50 for letter grade in order to satisfy the QRD requirement.

CS50 satisfies 哈佛学院’s Quantitative Reasoning with Data (QRD) requirement, which “introduces students to mathematical, statistical, and computational methods.” CS50 equips students with methods with which they can draw inferences and make predictions on real data, and CS50 teaches students how to assess uncertainty and critically think 关于 the limitations of these methods. Indeed, among the 课程’s goals are:

  1. Computational Thinking. Students are introduced to computational thinking, the application of methodical, algorithmic thought processes to problems, many of which involve raw data, and all of which involve information in some form as input. Students learn how to control flow, whereby students learn to reason that “if X is true, then Y will happen,” where X might be the simplest of 问题 or one involving multiple dependencies. For instance, students are asked to consider characteristics of data that influence how best to analyze it.
  2. Mathematical and Statical Methods. Students learn various algorithmic techniques and will explore their performances using a framework for evaluation, asymptotic notation, via which students can describe upper and lower bounds on 算法’ running 时间. Students ultimately learn quantitative approaches to analyzing data, particularly in the context of 算法, with hypothetical and actual data sets alike. For instance, students are asked to identify properties of a good hash function, and design their own algorithm and then assess the asymptotic complexity thereof.
  3. Real Data. Students apply quantitative methods to real-世界 data (e.g., literature, photographs, dictionaries, 电影, equity markets, et al.) to prepare them to solve real-世界 problems after CS50. For instance, students query an API for (nearly) real-时间 financial data so as to implement and manage virtual portfolios of stocks.

Lateness Policy

You have a semester-long allowance of 72 hours (divided into 1-minute segments) to turn in 问题集 (not quizzes) late. This allowance should be used carefully (if at all!), but can otherwise be allocated in any manner of your choosing, which means that you 五月:

  • Use just over 7 hours on each 问题集; or
  • Use 9 hours and 22 minutes on one 问题集, 30 hours and 11 minutes on another, 54 minutes on a third, etc.

The amount of this allowance “charged” to a 问题集 is equal to the lateness of the latest part of that 问题集 turned in (including the form), for 问题集 with multiple parts. Once the 72-hour allowance has been exhausted, then from that point on the 课程 will begin to impose a 0.1% deduction to your grade for all problems in a 问题集 for each minute it is turned in late. Therefore, once your allowance is exhausted, for 示例:

  • Any work turned in 10 minutes late will earn 99% of the points it would have earned had it been turned in on 时间 (a 1.0% deduction).
  • Any work turned in 60 minutes late will earn 94% of the points it would have earned had it been turned in on 时间 (a 6.0% deduction).
  • Any work turned in 1,000 minutes (16 hours, 40 minutes) late is effectively zeroed, as that would be a 100.0% deduction.

Furthermore, whether availing yourself of your semester-long allowance (partially or fully) or not, the absolute latest any single 问题集 or portion thereof 五月 be turned in for credit is 72 hours from its original 截止时间. Gradescope will not allow any submissions after that point, nor will the 课程 ordinarily accept them via some other means.

Late work will not be accepted on quizzes, or any portion of the 最终项目.
