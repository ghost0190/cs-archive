The test will be adminstered primarily through Canvas, using Proctorio, which is remote-proctoring software that works within your web browser, monitoring your 视频 and screen activity during the test. To use Proctorio, you’ll need to install a browser extension, which is compatible with Brave, Edge, Google Chrome, and Opera, but not Safari. The extension can be uninstalled once the test is complete. You will have exactly three (3) hours to complete the test; you must 提交 within 3 hours of starting.
