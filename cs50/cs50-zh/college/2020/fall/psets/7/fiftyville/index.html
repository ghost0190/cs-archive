Fiftyville

Write SQL queries to solve a mystery.

A Mystery in Fiftyville

The CS50 Duck has been stolen! The town of Fiftyville has called upon you to solve the mystery of the stolen duck. Authorities believe that the thief stole the duck and then, shortly afterwards, took a flight out of town with the help of an accomplice. Your goal is to identify:

  • Who the thief is,
  • What city the thief escaped to, and
  • Who the thief’s accomplice is who helped them escape

All you know is that the theft took place on 七月 28, 2020 and that it took place on Chamberlin Street.

How will you go 关于 solving this mystery? The Fiftyville authorities have taken some of the town’s records from around the 时间 of the theft and prepared a SQLite database for you, fiftyville.db, which contains tables of data from around the town. You can query that table using SQL SELECT queries to access the data of interest to you. Using just the information in the database, your task is to solve the mystery.

入门

Here’s how to 下载 this problem into your own CS50 IDE. Log into CS50 IDE and then, in a terminal window, execute each of the below.

  • Execute cd to ensure that you’re in ~/ (i.e., your 首页 directory, aka ~).
  • If you haven’t already, execute mkdir pset7 to make (i.e., create) a directory called pset7 in your 首页 directory.
  • Execute cd pset7 to change into (i.e., 打开) that directory.
  • Execute wget https://cdn.cs50.net/2020/fall/psets/7/fiftyville/fiftyville.zip to 下载 a (compressed) ZIP file with this problem’s distribution.
  • Execute unzip fiftyville.zip to uncompress that file.
  • Execute rm fiftyville.zip followed by yes or y to delete that ZIP file.
  • Execute ls. You should see a directory called fiftyville, which was inside of that ZIP file.
  • Execute cd fiftyville to change into that directory.
  • Execute ls. You should see a fiftyville.db file, a log.sql file, and an answers.txt file.

规格说明

For this problem, equally as important as solving the mystery itself is the process that you use to solve the mystery. In log.sql, keep a log of all SQL queries that you run on the database. Above each query, label each with a comment (in SQL, comments are any lines that begin with --) describing why you’re running the query and/or what information you’re hoping to get out of that particular query. You can use comments in the log file to add additional 笔记 关于 your thought process as you solve the mystery: ultimately, this file should serve as evidence of the process you used to identify the thief!

Once you solve the mystery, complete each of the lines in answers.txt by filling in the 姓名 of the thief, the city that the thief escaped to, and the 姓名 of the thief’s accomplice who helped them escape town. (Be sure not to change any of the existing text in the file or to add any other lines to the file!)

Ultimately, you should 提交 both your log.sql and answers.txt files.

Walkthrough

提示

  • Execute sqlite3 fiftyville.db to begin running queries on the database.
    • While running sqlite3, executing .tables will list all of the tables in the database.
    • While running sqlite3, executing .schema TABLE_NAME, where TABLE_NAME is the 姓名 of a table in the database, will show you the CREATE TABLE command used to create the table. This can be helpful for knowing which columns to query!
  • You 五月 find it helpful to start with the crime_scene_reports table. Start by looking for a crime scene report that matches the 日期 and the 地点 of the crime.
  • See this SQL keywords reference for some SQL syntax that 五月 be helpful!
