Understanding

Provided to you is a file called songs.db, a SQLite database that stores data from Spotify 关于 歌曲 and their artists. This dataset contains the top 100 streamed 歌曲 on Spotify in 2018. In a terminal window, run sqlite3 songs.db so that you can begin executing queries on the database.

First, when sqlite3 prompts you to provide a query, type .schema and press enter. This will output the CREATE TABLE statements that were used to generate each of the tables in the database. By examining those statements, you can identify the columns present in each table.

Notice that every artist has an id and a name. Notice, too, that every song has a name, an artist_id (corresponding to the id of the artist of the song), as well as values for the danceability, energy, key, loudness, speechiness (presence of spoken words in a track), valence, tempo, and duration of the song (measured in milliseconds).

The challenge ahead of you is to write SQL queries to 答案 a variety of different 问题 by selecting data from one or 更多 of these tables. After you do so, you’ll reflect on the ways Spotify might use this same data in their annual Spotify Wrapped campaign to characterize listeners’ habits.

实现细节

For each of the following problems, you should write a single SQL query that outputs the results specified by each problem. Your response must take the form of a single SQL query, though you 五月 nest other queries inside of your query. You should not assume anything 关于 the ids of any particular 歌曲 or artists: your queries should be accurate even if the id of any particular song or person were different. Finally, each query should return only the data necessary to 答案 the 问题: if the problem only asks you to output the names of 歌曲, for 示例, then your query should not also output each song’s tempo.

  1. In 1.sql, write a SQL query to list the names of all 歌曲 in the database.
    • Your query should output a table with a single column for the 姓名 of each song.
  2. In 2.sql, write a SQL query to list the names of all 歌曲 in increasing order of tempo.
    • Your query should output a table with a single column for the 姓名 of each song.
  3. In 3.sql, write a SQL query to list the names of the top 5 longest 歌曲, in descending order of length.
    • Your query should output a table with a single column for the 姓名 of each song.
  4. In 4.sql, write a SQL query that lists the names of any 歌曲 that have danceability, energy, and valence greater than 0.75.
    • Your query should output a table with a single column for the 姓名 of each song.
  5. In 5.sql, write a SQL query that returns the average energy of all the 歌曲.
    • Your query should output a table with a single column and a single row containing the average energy.
  6. In 6.sql, write a SQL query that lists the names of 歌曲 that are by Post Malone.
    • Your query should output a table with a single column for the 姓名 of each song.

  7. In 7.sql, write a SQL query that returns the average energy of 歌曲 that are by Drake.
    • Your query should output a table with a single column and a single row containing the average energy.
    • You should not make any assumptions 关于 what Drake’s artist_id is.
  8. In 8.sql, write a SQL query that lists the names of the 歌曲 that feature other artists.

提示

See this SQL keywords reference for some SQL syntax that 五月 be helpful!

List the names of all 歌曲 in the database

Recall that, to select all values in a table’s column, you can use SQL’s SELECT keyword. SELECT is followed by the column (or columns) you’d like to select, which is in turn followed by FROM table where table is the 姓名 of the table you’d like to select from.

In 1.sql, then, try writing the following:

-- All songs in the database.
SELECT name
FROM songs;
List the names of all 歌曲 in increasing order of tempo

Recall that SQL has an ORDER BY keyword, by which you can order the results of your query by the value in a certain column. For 示例, ORDER BY tempo will order results by the column tempo.

In 2.sql, then, try writing the following:

-- All songs in increasing order of tempo.
SELECT name
FROM songs
ORDER BY tempo;
List the names of the top 5 longest 歌曲, in descending order of length

Recall that ORDER BY need not always 排序 in ascending order. You can specify that your results be sorted in descending order by appending DESC. For 示例, ORDER BY duration_ms DESC will list results in descending order, by duration.

And recall, too, that LIMIT n can specify that you only want the first \(n\) rows that match a specific query. For 示例, LIMIT 5 will return only the first five results of the query.

In 3.sql, then, try writing the following:

-- The names of the top 5 longest songs, in descending order of length.
SELECT name
FROM songs
ORDER BY duration_ms DESC
LIMIT 5;
List the names of any 歌曲 that have danceability, energy, and valence greater than 0.75

Recall that you can 滤镜 results in SQL with WHERE clauses, which are followed by some condition which typically tests the values in a row’s columns.

Recall, too, that SQL’s operators function much the same way as C’s. For 示例, > evaluates to “true” when the value on the left is greater than the value on the right. You 五月 chain these expressions together, using AND or OR, to form one larger condition.

In 4.sql, then, try writing the following:

-- The names of any songs that have danceability, energy, and valence greater than 0.75.
SELECT name
FROM songs
WHERE danceability > 0.75 AND energy > 0.75 AND valence > 0.75;
Find average energy of all the 歌曲

Recall that SQL supports keywords not just to select particular rows, but also to aggregate the data in those rows. In particular, you might find the AVG keyword (to compute averages) useful. To aggregate the results of a column, just apply the aggregation function to that column. For 示例, SELECT AVG(energy) will find the average of the values in the energy column for the given query.

In 5.sql, then, try writing the following:

-- The average energy of all the songs.
SELECT AVG(energy)
FROM songs;
List the names of 歌曲 that are by Post Malone

Notice that, if you execute .schema songs in your sqlite prompt, the songs table has song names but not artist names! Instead, songs has an artist_id column. To list the names of 歌曲 by Post Malone, then, you’ll first need to identify Post Malone’s artist id.

-- Identify Post Malone's artist id
SELECT id
FROM artists
WHERE name = 'Post Malone';

This query returns 54. Now, you could query the songs table for any song with Post Malone’s id.

SELECT name
FROM songs
WHERE artist_id = 54;

But, per the 规格说明, you should be mindful not to assume knowledge of any ids. You could improve the design of this query by nesting your two queries.

In 6.sql, then, try writing the following:

-- The names of songs that are by Post Malone.
SELECT name
FROM songs
WHERE artist_id =
(
    SELECT id
    FROM artists
    WHERE name = 'Post Malone'
);
Find the average energy of 歌曲 that are by Drake

Notice that, similar to the 上一页 query, you’ll need to combine multiple tables to successfully run this query. You could again use nested subqueries, but consider another approach too!

Recall that you can use SQL’s JOIN keyword to combine multiple tables into one, so long as you specify which columns across those tables should ultimately match. For 示例, the following query joins the songs and artists tables, indicating that the artist_id column in the songs table and the id column in the artists table should match:

SELECT *
FROM songs
JOIN artists ON songs.artist_id = artists.id

With these two tables combined, it’s only a matter of filtering your selection to find the average energy of 歌曲 by Drake.

In 7.sql, then, try writing the following:

-- The average energy of songs that are by Drake
SELECT AVG(energy)
FROM songs
JOIN artists ON songs.artist_id = artists.id
WHERE artists.name = 'Drake';
List the names of the 歌曲 that feature other artists

For this query, 笔记 that 歌曲 which feature other artists typically have some mention of “feat.” in their title. Recall that SQL’s LIKE keyword can be used to match strings with certain phrases (like “feat.”!). To do so, you can use %: a wildcard character that matches any sequence of characters.

In 8.sql, then, try writing the following:

-- The names of songs that feature other artists.
SELECT name
FROM songs
WHERE name LIKE '%feat.%';

Spotify Wrapped

Spotify Wrapped is a feature presenting Spotify users’ 100 most played 歌曲 from the past year. In 2021, Spotify Wrapped calculated an “音频 Aura” for each user, a “reading of [their] two most prominent moods as dictated by [their] top 歌曲 and artists of the year.” Suppose Spotify determines an 音频 aura by looking at the average energy, valence, and danceability of a person’s top 100 歌曲 from the past year. In answers.txt, reflect on the following 问题:

  • If songs.db contains the top 100 歌曲 of one listener from 2018, how would you characterize their 音频 aura?
  • Hypothesize 关于 why the way you’ve calculated this aura might not be very representative of the listener. What better ways of calculating this aura would you propose?

Be sure to 提交 answers.txt along with each of your .sql files!
