我应该选修这门课程吗？

我或我的孩子是否太年轻不适合选修这门课程？

我们的课程可能最适合 12 岁及以上的学习者。年龄较小的学习者可能需要家长的帮助。请注意，你当地的法律和政策可能会阻止特定年龄以下的学习者使用与此课程相关的免费第三方服务。因此，年龄较小的学习者在注册这些免费服务时可能需要你的帮助。

这门课程有前置要求吗？

虽然你不必修读或出示通过先修课程的证明，但我们强烈建议你查看我们的 课程地图 以确定这门课在你目前的学习阶段是否适合你.

这门课程可以用于满足我的大学、学院或学校的官方学术要求吗？

我们的免费和认证证书并非来自哈佛或其任何附属机构的认证学术学位。我们提供这些证书用于自学和职业发展用途。

世界各地的学校和大学对于具体什么可以接受作为学分转换有不同的规定。因此，你应该咨询你的学术顾问关于你个人的情况。我们的证书有可能（但你需要向你的顾问核实）满足他们的要求。事实上，我们的一些课程（通过 edX 的）被 美国教育委员会 (ACE) 推荐为大学学分，你所在的学术机构可能会认可。

如果你正在寻找经认证的学术课程或本科或研究生级别的证书，可以考虑 哈佛拓展学院.

如何利用美国教育委员会（ACE）的学分推荐？

ACE, 用他们网站的话说, 帮助学习者寻求 “快速启动他们的大学生涯获得学分转换，或用徽章开启新的就业机会。” 此外, 他们指出 “ACE 国家指南可用于查找提供大学学分或能力认证推荐的课程和考试。”

我们的部分课程通过 edX 的认证证书计划，已被收录在 ACE 国家指南中。截至这些常见问题的最新修订，我们出现在 ACE 国家指南中的课程包括：

  • CS50x: 计算机科学导论;
  • CS50 AI: 人工智能导论（Python 实现）; 以及
  • CS50 Web: Web 编程（Python 与 JavaScript）.

你现在或未来的学院或大学可能会接受我们那些已被收录在 ACE 国家指南中并且你已经获得 edX 认证证书的课程。但是，强烈建议你在选修我们的课程之前向你的学校核实，如果你希望这些课程被接受为官方学分。免费的 CS50 证书不能用于满足 ACE 的要求。

获取此类学分的流程如下：

  1. 从 ACE 国家指南中选择我们的一门课程 (见上方).
  2. 向你的学术机构核实他们是否会接受 ACE 国家指南中列出的这门课程作为学分.
  3. 注册课程的 edX 认证通道并完成支付。你可以使用以下链接之一：:
    • CS50x
    • CS50 AI
    • CS50 Web
  4. 获得并领取课程的 edX 认证证书.
  5. 从 edX 获取官方的 ACE 学分笔记或 ACE 成绩单。有时，仅 edX 认证证书可能就足以作为 ACE 证明文件，前提是认证证书明确包含 ACE 学分推荐。
  6. 在 Credly 上领取你的 ACE 学分徽章。edX 通常会在颁发 edX 认证证书时提供链接或邀请以领取 Credly 徽章。
  7. 保留你的 edX 认证证书、ACE 证明文件（如学分笔记或成绩单）以及 Credly 徽章。
  8. 在适当的时候，出示 这些证明文件 给你的学术机构.

如果你之前在 ACE 国家指南网站上列出的注册期间完成了课程并获得了认证证书，你将能够追溯获取以上内容。但是，课程完成必须在注册期间内，该期间会不时更改。如果你希望在你完成课程后升级为 edX 认证证书，在确认你的注册期间在 ACE 国家指南规定的期间内后（见上文），你可以查看我们的 证书升级说明.

所有关于 ACE 学分的咨询应直接联系 edX 支持。

我可以获得确认注册和课程详情的信函吗？

我们无法提供个性化的邮件详细说明你在这门课程中的注册情况。但是，欢迎你注册 edX 的 认证证书，用于提供你已注册该课程的证明。此外，你可以从 课程页面 了解更多信息。最后，关于课程的时间要求，你可以自行合计每周的课程讲座时间。对于时间必需的必需作业，最好估计每周的问题集需要 10-20 小时。

注册

如何注册这门课程？

你可以按照 课程页面 上的说明操作。

认证证书和 CS50 证书有什么区别?

一份 认证证书（你可以从 edX 购买）”可以为雇主、学校或其他机构提供证明，证明你已成功完成在线课程。”

一份 CS50 证书 是 CS50 本身的免费证书。

如果我注册了认证证书，还能获得免费证书吗？

是的。

必须注册 edX 吗？

是的。无论你追求哪种证书（免费或认证），你都必须注册 edX。

edX 要求我付费才能注册课程：如何获取免费证书？

最好在注册时仔细重新阅读 edX 网站上的问题。有一个"免费"或"旁听"选项，无需付费。

如果我将来想要 edX 认证证书，必须在开始课程前付费验证吗？

不需要！如果你想要 edX 的认证证书，你可以在课程最终截止时间前 10 天内的任何时间付费验证，甚至在完成课程所有作业之后也可以。但是，我们强烈建议，为避免可能延迟证书颁发的任何后勤问题，请在完成课程之前进行验证。否则，我们在下方提到的 30 天等待期只有在 edX 验证了你的身份之后才开始计算。因此，在完成课程后才注册认证证书，可能会导致你的认证证书延迟 30 天或更长时间才能收到。

如果我在完成课程后支付了认证证书，需要通知你们吗？

如果你在这个日历年完成了课程：不需要。只要你的 成绩册 显示你已完成这门课程，你将在向 edX 支付认证证书费用后 30 天内收到你的证书。

如果你在这个日历年之前完成了这门课程：是的。请将你的 CS50 证书副本、你用于完成这门课程的 edX 和 GitHub 用户名，以及你购买 edX 认证证书的收据发送给我们。你必须使用之前完成这门课程时所用的同一 edX 账户购买 edX 认证证书。

我可以为今年之前完成的 CS50 课程获取认证证书吗？

是的，我们可以为 2019 年至今的任何课程完成提供认证证书。前提是你能向我们发送你的 CS50 证书副本、你用于完成该课程的 edX 和 GitHub 用户名，以及你购买 edX 认证证书的收据。没有这些信息，我们无法提供此类证书。

如果我在这个日历年之前支付了认证证书，我需要再次付费吗?

不，你的验证一整年都有效，但如果已过期，你应该能够通过 edX 的仪表板重新验证自己。

追踪你的进度

如何知道我是否已完成证书的所有要求？

你的 成绩册 显示每个提交作业在此课程最新版本中的结果。你的 成绩册 顶部显示你在该课程中的当前状态，显示你已完成的必需作业数量。如果你的 成绩册 显示你未在该课程中注册，最好注册并开始完成必需作业。

这门课程需要多个作业在某些周提交，而在其他周只需一个作业。当你完成给定周的要求时（即在该周所有必需作业上获得 70% 或更高的分数），该周编号将以绿色显示，并且你的进度指示器将更新以反映这一点。

一旦你在所有必需作业上至少获得 70% 的分数，你将在该页面顶部看到一个绿色横幅，确认你已完成课程并为你提供获取证书的后续步骤。

这门课程的成绩册在哪？

CS50x 使用我们自己的 成绩册。如果你以前从未访问过该链接，你需要点击链接进行“注册”，这实际上只是启用你的 成绩册 访问权限！无论免费或认证证书，都必须在 edX 上注册。

为什么 成绩册 显示我未注册？

有很多潜在原因。最常见的原因如下。首先，你可能从未在该课程中注册过。其次，你可能从未将你的 edX 账户链接到你的成绩册。最好按照 成绩册 中的屏幕提示解决此问题并注册。

这门课程有分数吗？

不是。这门课程有数字分数。获得 70% 或更高分数的作业被视为通过。

我的成绩册只显示我是否达到问题及格线？如何查看我的实际分数？

你的 成绩册 会显示绿色勾号表示你通过了已提交的作业，红色叉号表示你未通过已提交的作业。

你的问题总分权重为正确性 75%，代码风格 25%。要获得表示完成的绿色勾号，你的总分必须达到 70% 或更高。例如，如果你的 check50 分数是 7/8，风格分数是 0.95，你的总分将是 (7/8 * 0.75) + (0.95 * 0.25) = 89%。你可以点击 成绩册 中的问题名称查看你的各项 check50 和 style50 分数。

我在前一年完成了作业或这门课程。为什么我的成绩册不再显示我之前的进度?

在每个日历年开始时，我们会清理我们的 成绩册 并“重置”它。你的进度取决于你上次提交课程作业的时间。

为什么 edX 认为我的分数是 0%？

这门课程不使用 edX 内置的成绩册，因此所有学生的分数在 edX 的成绩册中始终显示为 0%。不用担心，请查看你的 成绩册 获取实际结果。如果你最近完成了这门课程，edX 最多需要 30 天才能在 edX 仪表板上确认你的完成状态。

我在 edX 或 YouTube 上看了所有视频：为什么我没有证书?

这门课程有大量作业需要完成，此外还需要观看课程讲座。最好查看课程菜单，其中列出了课程的各种作业。

为什么我的 edX 仪表板显示我可以“继续”这门课程，即使我已经完成了?

你的 edX 仪表板可能会显示 View Course 或 Resume Course 作为便利功能，以便你可以返回或查看这门课程。这并不表示完成或未完成。

GitHub 禁用了我的账户。我该怎么办？

最好查阅 GitHub 关于账户恢复的文档。我们无法将你之前的进度转移到新的 GitHub 账户。此外，我们也无法从已禁用的 GitHub 账户中访问你的文件。如果你无法恢复对 GitHub 账户的访问权限，你将需要重新开始这门课程。

问题集、作业与评估

这门课程有考试吗？

这门课程没有总结性考试或”期末考试”。虽然我们在哈佛学院和哈佛拓展学院的课程通常有期末考试，但这门课程没有。你只需完成课程每周或每个模块中列出的作业即可。

“较少舒适”和“更多舒适”问题有什么区别? 两个都需要做吗?

在一些早期的问题集中，你可以在”较少舒适”和”更多舒适”问题之间进行选择。

“较少舒适”问题可以说是问题的”标准”版本，专为几乎没有或没有先前经验的学生设计。”更多舒适”问题是”挑战”版本，专为那些因先前学习或经验而认为自己水平较高的学生设计。因此，它们可能需要比该课程迄今已涵盖的更多的概念。

如果你发现自己真的在”更多舒适”版本上遇到困难，你应该切换到”较少”版本（或者如果你已经完成了该版本，就直接继续前进，也许在后面的周中再回看）。跳过问题比因为太过沮丧而完全退出这门课程要好。作为参考，在 2019 年秋季的哈佛班级中，只有 20-30% 的学生提交了”更多舒适”问题。

做”更多舒适”问题不会获得额外分数。如果你两个都提交了，得分较高的那个会计入你的整体课程进度。

你收到我的提交了吗？

一旦你按照作业规格说明的指示使用适当的 slug 执行 submit50 命令，你的 成绩册 将立即更新你的通过状态，前提是你的提交是及格的！在使用 submit50 之前，最好先用 check50 确保你在提交前已完成整个问题。

我提交了一个项目，但我的成绩册中没有显示我已提交的内容。为什么?

只要你按照作业规格说明的指示使用适当的 slug 执行了 submit50 命令，你的通过状态应立即发布到你的 成绩册。首先，最好在你的作业上运行 check50 以确保它满足要求。其次，如果仍然不起作用，请确保你用于登录 CS50.dev 的 GitHub 用户名与你的 成绩册 顶部显示的 GitHub 用户名相同。

如果我提交了一个问题但没有达到 70% 的及格线，我可以重新提交吗？

是的！你可以重新提交；我们只会将你最近的提交计入你的进度。

如果我的 check50 分数不符合预期，可能是什么原因？

你的 check50 分数是准确的。运行 check50 后，请注意，会提供一个链接指向你的结果。请注意，check50 会检查是否精确满足各项检查。因此，如果它期望输出后有换行符而实际没有，该检查将显示为未满足。在某些情况下，check50 结果中的预期输出和实际输出可能看起来完全相同。在这种情况下，最好考虑空格和其他不可见字符是否在起作用。当然，也有可能你误解了作业的某部分内容，需要重新阅读问题集规格说明。

如果我的代码风格分数不符合预期，可能是什么原因？

你的代码风格分数将基于提交中每个源代码文件的 style50 结果。运行 submit50 时，请确保你的文件夹只包含问题集所需的必要文件。如果有任何多余的测试文件，它们也会计入你的分数。从文件夹中删除多余文件并重新提交以获取更新的风格分数。

为什么我没有通过 我的最终项目？

提交你的最终项目后，你可以在你的 成绩册 中查看提交内容，了解你的分数详情以及未通过的原因。

未能在你的最终项目上获得通过分数的最常见原因是你没有遵循 最终项目规格说明。

未能在你的最终项目上获得通过分数的第二个最常见原因与你的文档有关（你最终项目的 README 或 DESIGN 文件）。当你的 README 或 DESIGN 文档未满足规定要求时，你将无法通过最终项目。文档文件应该相当详尽。未完成详尽文档文件（包括多个段落）的学生将不会获得通过分数。我们强烈建议你创建一个详尽的文档文件，包括 最终项目规格说明 中提到的具体章节。此外，请注意，最终项目规格说明 包含了你文档的大致字数要求。遵循这些规格说明将确保你的文档文件包含你通过所需的所有必要细节。

截止日期

截止日期是什么时候？

这门课程没有针对作业的个人截止日期。欢迎你按照自己的节奏学习和提交。

课程的总体截止时间目前是 2025 年 12 月 31 日晚上 11:59 UTC（有时称为 Zulu 时间）。为方便起见，我们通常会以你的本地时区显示此时间 (2025-12-31T23:59:00+00:00).

如果所有必需的工作在上述时间之前提交并最终获得满意分数（无论是在该截止时间之前或之后不久），你将被视为已完成这门课程。

如果我在 2025 年 12 月 31 日结束前没有完成这门课程，会发生什么?

如果这门课程延长到下一个年份，2025 年完成的所有工作将结转至 2026 年。如果这门课程在 2025 年之后更新为 2026 版本，你可能只能提交 2026 版本的问题集，并且需要满足当时该课程中的任何要求。2024 年及之前提交的工作将不会结转到 2026 年。

如果我在这个日历年之前开始了 CS50x，我可以继续吗?

是的，2024 年任何已完成1的问题都已结转至你的 CS50x 2025 成绩册。你会看到已完成的问题标有绿色勾号。今后，你必须提交 CS50x 2025 的问题集。来自本课程先前版本的作业不能用于学分。2024 年之前提交的作业不计入你在 2025 年的进度。

1 所谓已完成，是指你在上一个截止时间之前在该问题上获得了 70% 或更高的分数。

获取你的证书

如何获取我的免费 CS50 证书？

一旦你完成了这门课程并满足所有要求（见上文），你会看到你的 成绩册 页面上出现一个链接，允许你申请免费的 CS50 证书，就像 这里展示的 一样。该链接将在你收到最后一个必需作业的分数并且 成绩册 中的进度条显示课程完成后大约四小时内可用。此链接出现后，你应该使用你的 GitHub 凭据登录。如果访问有困难，请尝试退出 GitHub 并重新登录，然后重新访问链接以下载你的证书。请务必在截止时间 之前 下载你的免费证书。

如何从 edX 获取我的认证证书？

每三周，CS50 的工作人员会向 edX 提供已满足课程要求（在每个必需问题上至少获得 70% 的分数）的学生名单。通常，在此之后的一周内，edX 会生成学生的认证证书（适用于已验证身份的学生），届时它们应自动出现在 edX 的 仪表板 上。因此，在你满足课程要求后，edX 生成你的认证证书最多可能需要 30 天。请注意，edX 不会 通知 你，所以请务必定期检查你的仪表板。

如果自你满足所有要求以来已经过了 30 天以上，并且尽管你一直持有有效的验证状态，但仍然没有收到证书，请发送邮件至 certificates@cs50.harvard.edu 并附上你的详细信息。请勿提前发邮件；我们不接受加急处理认证证书的请求。

可以加快 edX 颁发我的认证证书吗？

No.

为什么 30 天后我还没有收到认证证书？

首先，请记住你的认证 edX 证书将在满足三个条件后的最多 30 天内由 edX 颁发：(a) 你的 成绩册 显示你已完成所有必需作业，每项至少获得 70% 或更高的分数，(b) 你已向 edX 付款并完成他们的验证流程，在你的 edX 仪表板上获得验证徽章，以及 (c) 你已将你的 成绩册 链接到你的 edX 账户。因此，你应确保自以上三个条件全部满足以来已过去 30 天。

其次，只有当你将你的 成绩册 链接到 edX 时，我们才能通知 edX 你的通过状态。请访问你的 成绩册，确保页面顶部没有出现金色条幅说明你必须将你的 成绩册 链接到你的 edX 账户。如果看到这样的金色条幅，请完成链接过程。然后，重新阅读上面关于你预计何时收到证书的时间说明。

最后，如果你仍然没有收到你的 edX 证书，最好确认你的 成绩册 顶部显示的 edX 用户名与你的 edX 仪表板 顶部显示的 edX 用户名相同。如果这些用户名之间存在不匹配，你需要通知 edX 将你的验证付款转移到正确的用户名，因为我们可能已经通知他们你的 成绩册 顶部显示的 edX 用户名已通过这门课程。

什么名字会出现在我的证书上?

免费证书将包含你在申领证书时提供的名字。你需要在兑换过程中亲自输入你希望显示在证书上的名字。确保你输入了你想在证书上显示的名字!

通过 edX 提供的认证证书将包含与你的 edX 账户关联的名字。

我可以更改我证书上的名字吗?

不，我们无法更改你的证书上的名字。因为我们依赖你正确输入名字，而且由于我们合作的学生数量庞大，我们无法提供名字更改。你可以升级为认证证书，并通过邮件联系 info@edX.org 与 edX 沟通关于你的认证 edX 证书上显示什么名字。

你们提供印刷版证书吗？

不提供。最好将你的数字证书带到当地可以为你打印的打印店。
