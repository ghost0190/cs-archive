替换

要解决的问题

In a 替换 cipher, we “encrypt” (i.e., conceal in a reversible way) a message by replacing every letter with another letter. To do so, we use a key: in this case, a mapping of each of the letters of the alphabet to the letter it should correspond to when we encrypt it. To “decrypt” the message, the receiver of the message would need to know the key, so that they can reverse the process: translating the encrypt text (generally called ciphertext) 返回 into the original message (generally called plaintext).

一份 key, 例如, might be the string NQXPOMAFTRHLZGECYJIUWSKDVB. This 26-character key 意思s that A (the first letter of the alphabet) should be converted into N (the first character of the key), B (the second letter of the alphabet) should be converted into Q (the second character of the key), and so forth.

一份 message like HELLO, then, would be encrypted as FOLLE, replacing each of the letters according to the mapping determined by the key.

In 名为 substitution.c in 的文件夹中名为 substitution, 创建一个 program that enables you to encrypt messages using a 替换 cipher. At the时间 the user executes the program, they should decide, by providing a 命令行参数, on what the key should be in the secret message they’ll provide at runtime.

演示

规格说明

Design and 实现一个 program, substitution, that encrypts messages using a 替换 cipher.

  • Implement your program in 名为 substitution.c in a directory called substitution.
  • 你的程序必须 accept a single 命令行参数, the key to use 的 替换. The key itself should be 不区分大小写, so whether any character in the key is uppercase or lowercase should not affect the behavior of your program.
  • If your program is executed without any 命令行参数s or with 更多 than one 命令行参数, your program should print an error message of your choice (with printf) and return from main a value of 1 (which tends to signify an error) immediately.
  • If the key is invalid (as by not containing 26 characters, containing any character that is not an alphabetic character, or not containing each letter exactly once), your program should print an error message of your choice (with printf) and return from main a value of 1 immediately.
  • 你的程序必须 output plaintext: (without a 换行符) and then 提示用户输入 a string of plaintext (using get_string).
  • 你的程序必须 output ciphertext: (without a 换行符) followed by the plaintext’s corresponding ciphertext, with each alphabetical character in the plaintext substituted 的 corresponding character in the ciphertext; non-alphabetical characters should be outputted unchanged.
  • 你的程序必须 preserve case: capitalized letters must remain capitalized letters; lowercase letters must remain lowercase letters.
  • After outputting ciphertext, you should print a 换行符. 你的程序应该 then exit by returning 0 from main.

You might find one or 更多 functions declared in ctype.h to be helpful, per manual.cs50.io.

如何测试

Correctness

In your terminal, execute the below to check your work’s correctness.

check50 cs50/problems/2025/x/substitution
How to Use debug50

Looking to run debug50? You can do so as follows, after compiling your code successfully with make,

debug50 ./substitution KEY

wherein KEY is the key you give as a 命令行参数 to your program.请注意， running

debug50 ./substitution

will (ideally!) cause your program end by prompting the user for a key.

Style

Execute the below to evaluate the style of your code using style50.

style50 substitution.c
