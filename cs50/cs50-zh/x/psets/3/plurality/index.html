多数制

要解决的问题

选举有各种形式和规模。在英国，首相由君主正式任命，君主通常会选择在下议院赢得最多席位的政党领导人。美国使用多步骤的选举人团流程，公民投票决定每个州如何分配选举人，然后由选举人选举总统。

不过，也许最简单的选举方式是一种通常被称为”多数制投票”的方法（也称为”简单多数制”或”赢者通吃”）。在多数制投票中，每位选民投票给一位候选人。选举结束时，得票最多的候选人被宣布为选举的获胜者。

理解 plurality.c 中的代码

每当你要扩展现有代码的功能时，最好先确保你理解了它当前的状态。

首先看看文件的顶部。行 #define MAX 9 是此处使用的语法，意思是 MAX 是一个常量（等于 9），可以在整个程序中使用。在这里，它表示一场选举中候选人的最大数量。

// Max number of candidates
#define MAX 9

注意，plurality.c 随后使用这个常量来定义一个全局数组——即任何函数都可以访问的数组。

// Array of candidates
candidate candidates[MAX];

但在这种情况下，candidate 是什么？在 plurality.c 中，candidate 是一个 struct（结构体）。每个 candidate 有两个字段：一个名为 name 的 string，表示候选人的姓名；一个名为 votes 的 int，表示该候选人获得的票数。

// Candidates have name and vote count
typedef struct
{
    string name;
    int votes;
}
candidate;

现在，看看 main 函数本身。看看你能否找到程序设置全局变量 candidate_count 的位置，它表示选举中候选人的数量。

// Number of candidates
int candidate_count;

那么它把命令行参数复制到数组 candidates 的位置呢？

// Populate array of candidates
candidate_count = argc - 1;
if (candidate_count > MAX)
{
    printf("Maximum number of candidates is %i\n", MAX);
    return 2;
}
for (int i = 0; i < candidate_count; i++)
{
    candidates[i].name = argv[i + 1];
    candidates[i].votes = 0;
}

以及它要求用户输入选民数量的位置呢？

int voter_count = get_int("Number of voters: ");

然后，程序让每位选民输入一次投票，为所投的每位候选人调用 vote 函数。最后，main 调用 print_winner 函数来输出选举的获胜者（或多位获胜者）。我们留给你来找出实现此功能的代码。

完成 vote 函数

接下来，完成 vote 函数。

  • 请注意，vote 的签名 bool vote(string name) 表明它接受一个参数，即一个名为 name 的 string，表示被投票的候选人的姓名。
  • vote 应返回一个 bool，其中 true 表示投票成功，false 表示投票未成功。

解决此问题的一种方法如下：

  1. 遍历每位候选人
    1. 检查候选人的姓名是否与输入 name 匹配
      1. 如果是，增加该候选人的票数并返回 true
      2. 如果不是，继续检查
  2. 如果检查所有候选人后都没有匹配，返回 false

完成 print_winner 函数

最后，完成 print_winner 函数。

  • 该函数应输出选举中获得最多票数的候选人的姓名，然后输出一个换行符。
  • 如果有多位候选人都获得了最多票数，选举可能以平局结束。在这种情况下，你应该输出每位获胜候选人的姓名，分别放在不同的行上。

你可能认为排序算法最能解决此问题：想象一下按票数对候选人进行排序，然后输出得票最多的候选人或各位候选人。不过，回想一下，排序可能开销很大：即使是归并排序——最快的排序算法之一——运行时间复杂度也是 O(N log(N))。

考虑一下，解决此问题你只需要两条信息：

  1. 最高票数
  2. 拥有该票数的候选人（或各位候选人）

因此，一个好的解决方案可能只需要两次搜索。写一些伪代码来提醒自己做这件事：

如何测试

请务必 测试你的代码以确保 it handles…

  • 任意数量候选人的选举 (up to the MAX of 9)
  • 按姓名投票给候选人
  • 投票给不在选票上的候选人的无效投票
  • 如果只有一位获胜者，输出选举的获胜者
  • 如果有多位获胜者，输出选举的获胜者们
