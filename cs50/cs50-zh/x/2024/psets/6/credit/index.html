Credit

要解决的问题

In a filed called credit.py in 的文件夹中名为 sentimental-credit, 编写一个 program that prompts the user for a credit card number and then reports (via print) whether it is a valid American Express, MasterCard, or Visa card number, exactly as you did in 问题集 1. Your program this时间 should be written in Python!

演示

规格说明

  • So that we can automate some tests of your code, we ask that your program’s last line of output be AMEX\n or MASTERCARD\n or VISA\n or INVALID\n, nothing 更多, nothing 较少.
  • For simplicity, you 五月 assume that the user’s input will be entirely numeric (i.e., devoid of hyphens, as might be printed on an actual card).
  • Best to use get_int or get_string from CS50’s library to get users’ input, depending on how you to decide to implement this one.

提示

  • It’s possible to use regular expressions to validate user input. You might use Python’s re module, 例如, to check whether the user’s input is indeed a sequence of digits of the correct length.

如何测试

While check50 is avai实验le for this problem, you’re encouraged to first test your code on your own for each of the following.

  • Run your program as python credit.py, and wait for a prompt for input. Type in 378282246310005 and press enter. 你的程序应该 output AMEX.
  • Run your program as python credit.py, and wait for a prompt for input. Type in 371449635398431 and press enter. 你的程序应该 output AMEX.
  • Run your program as python credit.py, and wait for a prompt for input. Type in 5555555555554444 and press enter. 你的程序应该 output MASTERCARD.
  • Run your program as python credit.py, and wait for a prompt for input. Type in 5105105105105100 and press enter. 你的程序应该 output MASTERCARD.
  • Run your program as python credit.py, and wait for a prompt for input. Type in 4111111111111111 and press enter. 你的程序应该 output VISA.
  • Run your program as python credit.py, and wait for a prompt for input. Type in 4012888888881881 and press enter. 你的程序应该 output VISA.
  • Run your program as python credit.py, and wait for a prompt for input. Type in 1234567890 and press enter. 你的程序应该 output INVALID.
