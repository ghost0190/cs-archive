你好, 世界

要解决的问题

Thanks to Professor Brian Kernighan (who taught CS50 when David took it!), “你好, 世界” has been implemented in hundreds of languages. Let’s add your implementation to the list!

In 名为 hello.c, in 的文件夹中名为 world, 实现一个 program in C that prints hello, world\n, and that’s it!

提示

Here’s the actual code you should write! (Quite the 提示, huh?) Best to type it自己, though, rather than copy/paste, so that you start to develop some “muscle 内存” for writing code.

#include <stdio.h>

int main(void)
{
    printf("hello, world\n");
}

演示

Here’s a demo of what should happen when you compile and execute your program.

How to Begin

打开 VS Code.

Start by clicking inside your terminal window, then execute cd by itself. 你应该 find that its “prompt” resembles the below.

$

下一页 execute

mkdir world

to make 的文件夹中名为 world in your codespace.

Then execute

cd world

to change directories into that folder. 你应该 now see your terminal prompt as world/ $. You can now execute

code hello.c

to create 名为 hello.c in which you can write your code.

如何测试

回忆一下 you can compile hello.c with:

make hello

If you don’t see an error message, it compiled successfully! You can confirm as much with

ls

which should list not only hello.c (which is 源代码) but also hello (which is machine code).

If you do see an error message, try to fix your code and try to compile it again. If you don’t understand the error message, though, try executing

help50 make hello

for advice.

Once your code compiles successfully, you can execute your program with:

./hello

Correctness

Execute the below to evaluate the correctness of your code using check50, a command-line program that will output happy faces whenever your code passes CS50’s automated tests and sad faces whenever it doesn’t!

check50 cs50/problems/2024/x/world

Style

Execute the below to evaluate the style of your code using style50, a command-line program that will output additions (in green) and deletions (in red) that you should make to your program in order to improve its style. If you have trouble seeing those colors, style50 supports other modes too!

style50 hello.c
