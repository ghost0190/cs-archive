欢迎

This is CS50, 哈佛大学’s introduction to the intellectual enterprises of 计算机科学 and the art of 编程, for concentrators and non-concentrators alike, with or without prior 编程 experience. (Two thirds of CS50 students have never taken CS before.) 这门课程 teaches you how to solve problems, both with and without code, with an emphasis on correctness, design, and style. Topics include computational thinking, abstraction, 算法,数据结构, and 计算机科学 更多 generally. 问题集 inspired by the arts, humanities, social sciences, and sciences. 更多 than teach you how to program in one language, 这门课程 teaches you how to program fundamentally and how to teach自己 new languages ultimately. 这门课程 starts with a traditional but omnipresent language called C that underlies today’s newer languages, via which you’ll learn not only 关于 functions, variables, conditionals, loops, and 更多, but also关于如何 computers themselves work underneath the hood, 内存 and all. 这门课程 then transitions to Python, a higher-level language that you’ll understand all the 更多 because of C. Toward term’s end, 这门课程 introduces SQL, via which you can store data in 数据库, along with HTML, CSS, and JavaScript, via which you can create web and mobile apps alike. 课程 culminates in 一个最终项目.

How to Take 这门课程

Even if you are not a student at Harvard, you are 欢迎 to “take” 这门课程 for free via this 开放课件 by working your way through 这门课程’s eleven 周次 of material. For 每周, follow this workflow:

flowchart TD
    A[Watch Lecture] --> |recommended|B[Watch Section]
    一份 --> D
    B --> |recommended|C[Watch Shorts]
    B --> D[Submit 问题集]
    C --> D

And then 提交 这门课程’s 最终项目.

To 提交 这门课程’s 问题集 and 最终项目 for feedback, be sure to 创建一个n edX account, if you haven’t already. Ask问题 along the way via any of 这门课程’s 社区!

  • 如果你对 a 认证证书 from edX, 请在以下链接注册 cs50.edx.org instead.
  • 如果你对 a professional 证书 from edX
    • in web development, 请在以下链接注册 cs50.edx.org/programs/web instead.
    • in 人工智能, 请在以下链接注册 cs50.edx.org/programs/ai instead.
    • in Python 编程, 请在以下链接注册 cs50.edx.org/programs/python instead.
  • 如果你对 学分转换 and 认证 from 哈佛继续教育学院, 请在以下链接注册 web.dce.harvard.edu/extension/csci/e/50 instead.
  • 如果你对 学分转换 and 认证 from 哈佛暑期学校, 请在以下链接注册 web.dce.harvard.edu/夏季/csci/s/50 instead.

How to Teach 这门课程

If you are a teacher, you are 欢迎 to 采用或改编 these materials 为你自己的 课程, per the 许可协议. Additionally, we encourage teachers to 参加 CS50 教育工作坊 to learn 更多关于 CS50’s 课程体系、技术和教学方法.
