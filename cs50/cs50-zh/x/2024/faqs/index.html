我应该选修这门课程吗？

我或我的孩子是否太年轻不适合选修这门课程？

我们的课程可能最适合12岁及以上的学习者。年龄较小的学习者可能需要家长的帮助。请注意，你所在地区的法律和政策可能会阻止特定年龄以下的学习者使用本课程相关的免费第三方服务。因此，年龄较小的学习者在注册这些免费服务时可能需要你的帮助。

这门课程有前置要求吗？

虽然你不必修读或出示通过先修课程的证明，但我们强烈建议你查看我们的课程地图，以确定这门课在你目前的学习阶段是否适合你。

这门课程可以用于满足我的大学、学院或学校的官方学术要求吗？

我们的免费和认证证书并非经哈佛或其任何附属机构认证的学术证书。我们提供这些证书用于自学和职业发展用途。

世界各地的学校和大学对于他们会接受什么样的学分转换有不同的规定。因此，你应该咨询你的学术顾问关于你个人的情况。我们的一些课程（通过 edX 的）被 美国教育委员会（ACE） 推荐为大学学分，你所在的学术机构可能会认可。

如果你正在寻找经认证的学术课程或本科或研究生级别的证书，可以考虑 哈佛继续教育学院。

如何利用美国教育委员会（ACE）的学分推荐？

ACE，用他们网站的话说，帮助学习者寻求“快速启动他们的大学生涯，通过学分转换获得学分，或用徽章开启新的就业机会。”此外，他们还指出“ACE 国家指南可用于查找提供大学学分或能力认证推荐的课程和考试。”

我们的一些课程，通过 edX 的认证证书计划，已被收录在 ACE 国家指南中。截至这些常见问题的最新修订，我们出现在 ACE 国家指南中的课程包括：

  • CS50x: 计算机科学导论;
  • CS50 AI: 人工智能导论（Python 实现）；以及
  • CS50 Web: Web 编程（Python 与 JavaScript）。

你现在或将来的学院或大学可能会接受我们已被收录在 ACE 国家指南中且你已获得 edX 认证证书的课程。但是，我们强烈建议你在选修这些课程之前，先与你的学校核实他们是否会接受其作为官方学分。免费的 CS50 证书不能用于满足 ACE 的要求。

获取此类学分的流程如下：

  1. 从 ACE 国家指南中选择我们的一门课程（见上文）。
  2. 向你的学术机构核实他们是否会接受 ACE 国家指南中列出的这门课程作为学分。
  3. 注册课程的 edX 认证通道并完成支付。你可以使用以下链接之一：
    • CS50x
    • CS50 AI
    • CS50 Web
  4. 获得并领取课程的 edX 认证证书。
  5. 从 edX 获取官方的 ACE 学分笔记或 ACE 成绩单。有时，仅 edX 认证证书可能就足以作为 ACE 证明文件，前提是认证证书明确包含 ACE 学分推荐。
  6. 在 Credly 上领取你的 ACE 学分徽章。edX 通常会在颁发 edX 认证证书时提供链接或邀请以领取 Credly 徽章。
  7. 保留你的 edX 认证证书、ACE 证明文件（如学分笔记或成绩单）以及 Credly 徽章。
  8. 在适当的时候，向你的学术机构出示这些完成证明文件。

如果你之前在 ACE 国家指南网站上列出的注册期间完成了本课程并获得了认证证书，你将能够追溯获取上述内容。但是，本课程的完成必须在注册期间内，该期间会不时更改。如果你希望在完成课程后升级为 edX 认证证书，在确认你的注册期间在 ACE 国家指南规定的期间内后（见上文），你可以查看我们的证书升级说明。

所有关于 ACE 学分的咨询应直接联系 edX 支持。

我可以获得确认注册和课程详情的信函吗？

我们无法提供个性化的信函来详细说明你在这门课程中的注册情况。但是，欢迎你注册 edX 的 认证证书，用于提供你已注册该课程的证明。此外，你可以在 课程页面 上查看详情。至于课程的时间要求，你可以自行合计每周的课程讲座时长。对于必需作业的时间要求，最好估计每周问题集需要 10 到 20 小时。

注册

如何注册这门课程？

你可以按照 课程页面 上的说明进行注册。

认证证书和 CS50 证书有什么区别？

认证证书，可从 edX 购买，“可以为雇主、学校或其他机构提供证明，证明你已成功完成在线课程。”

CS50 证书 是 CS50 本身的免费证书。

如果我注册了认证证书，还能获得免费证书吗？

Yes.

必须注册 edX 吗？

是的。无论你追求的是免费还是认证证书，都必须注册 edX。

edX 要求我付费才能注册课程：如何获取免费证书？

最好在注册时仔细阅读 edX 网站上的问题。有一个“免费”或“旁听”选项，无需付费。

如果我将来想要 edX 认证证书，必须在开始课程前付费验证吗？

不用！如果你想要 edX 的认证证书，你可以在课程最终截止日期前 10 天的任何时间点支付验证费用，甚至在完成所有课程作业之后也可以。但是，我们强烈建议，为避免任何可能延迟证书发放的后勤问题，最好在完成课程之前进行验证。否则，我们在 下方 提到的 30 天等待期只会在 edX 完成你的身份验证后才开始计算。因此，在完成课程后再等待注册认证证书可能会使你收到证书的延迟达到 30 天甚至更久。

如果我在完成课程后支付了认证证书，需要通知你们吗？

如果你在本日历年完成了课程：不需要。只要你的 成绩册 显示你已完成本课程，你将在向 edX 支付认证证书费用后最多 30 天内收到你的证书。

如果你在本日历年之前完成了本课程：需要。请向我们发送你的 CS50 证书副本、你用于完成课程的 edX 和 GitHub 用户名、以及你购买 edX 认证证书的收据。你必须使用你之前完成课程时使用的同一个 edX 账号购买 edX 认证证书。

如果我在本日历年之前支付了认证证书的费用，我需要再次付费吗？

不需要，你的验证应该有效一整年，但如果已过期，你应该可以通过 edX 的 控制面板 重新验证自己。

追踪你的进度

如何知道我是否已完成证书的所有要求？

你的 成绩册 显示在本课程最新版本中每份作业提交的结果。你的 成绩册 顶部显示你当前在课程中的状态，显示你已完成的必需作业数量。如果你的 成绩册 显示你未注册课程，最好先注册并开始完成必需作业。

本课程要求某些周提交多份作业，而其他周只需提交一份作业。当你完成给定周的要求时（即在该周所有必需问题上获得 70% 或更高的分数），该周编号将显示为绿色，你的进度指示器也将更新以反映这一情况。

一旦你在所有必需作业上获得至少 70% 的分数，你将在该页面顶部看到一个绿色横幅，确认你已完成课程。

这门课程的成绩册在哪？

CS50x 使用我们自己的 成绩册。如果你以前从未访问过该链接，你需要点击“注册”链接，这实际上是启用你的 成绩册 访问！无论你是免费证书还是认证证书，都必须注册 edX。

Why does the 成绩册 say that I am not enrolled?

这有多种可能的原因。最常见的原因如下。首先，你可能之前从未注册过本课程。其次，你可能从未将你的 edX 账号关联到你的成绩册。最好按照 成绩册 中的屏幕提示来解决此问题并完成注册。

这门课程有分数吗？

不，本课程使用数字分数。一份获得 70% 或更高分数的作业被视为及格。

我的成绩册只显示我是否达到问题及格线？如何查看我的实际分数？

你的 成绩册 将显示绿色勾号表示你已通过提交的作业，显示红色叉号表示你未通过提交的作业。

你的总体问题分数以 75% 的正确性和 25% 的风格进行加权计算。为了获得表示完成的绿色勾号，你的总分数必须达到 70% 或更高。例如，如果你的 check50 分数是 7/8，而你的 style 分数是 0.95，那么你的总分数将是 (7/8 * 0.75) + (0.95 * 0.25) = 89%。你可以点击 成绩册 中的问题名称来查看你的单独 check50 和 style50 分数。

我在前一年完成了一份作业或本课程。为什么我的成绩册不再显示我之前的进度？

在每个日历年开始时，我们会清理并“重置”我们的 成绩册。你进度的变化取决于你最后一次提交课程作业的时间。

为什么 edX 认为我的分数是 0%？

本课程不使用 edX 内置的成绩册，因此所有学生的分数在 edX 的成绩册中始终显示为 0%。不用担心，请查看你的 成绩册 获取实际结果。

我在 edX 或 YouTube 上观看了所有视频：为什么我没有证书？

本课程除了观看课程讲座之外，还有大量必须完成的作业。最好查看课程菜单，其中列出了本课程的各项作业。

为什么我的 edX 控制面板显示我可以“继续学习”这门课程，尽管我已经完成了？

一旦你开始这门课程，你的控制面板上的 View Course 按钮将变为 Resume Course。这个按钮是为了你的便利，方便你返回这门课程，它不表示完成或未完成。

GitHub 禁用了我的账户。我该怎么办？

最好查阅 GitHub 关于账户恢复的 文档。我们无法将你之前的进度转移到新的 GitHub 账户。此外，我们无法从已禁用的 GitHub 账户访问你的文件。如果你无法恢复访问你的 GitHub 账户，你将需要重新开始这门课程。

问题集、作业与评估

这门课程有考试吗？

这门课程没有综合性考试或“期末考试”。虽然我们在哈佛学院和 Harvard Extension 的课程通常有期末考试，但这门课程没有。你只需要完成这门课程每周或每个模块中列出的作业即可。

“较简单”和“较困难”的问题有什么区别？两个都需要做吗？

在一些早期的问题集中，你可以在“较简单”和“较困难”的问题之间进行选择。

“较简单”的问题可以认为是问题的“标准”版本，为少有或没有先前经验的学生设计。“较困难”的问题是“挑战”版本，为那些由于在本课程之前已有学习/经验而认为自己能力较强的学生设计。因此，它们可能需要比该课程目前已覆盖的更多概念。

如果你发现自己在“较困难”版本上真的很挣扎，你应该转向“较简单”版本（或者如果你已经完成了，只管继续往前，也许在后面的某周再回头看）。对你来说，跳过这个问题比变得如此焦虑以至于完全退出这门课程更好。供参考，在 2019 年秋季的哈佛班级中，只有 20-30% 的学生提交了“较困难”的问题。

做“较困难”问题不会获得额外的分数。如果你提交了两个，得分最高的那个将被计入你的总体课程进度。

你收到我的提交了吗？

一旦你按照作业规格说明的指示，使用合适的 slug 执行 submit50 命令，如果你的提交通过，你的 成绩册 将立即更新你的通过状态！在使用 submit50 之前，最好先使用 check50 确保你在提交前已完成整个问题。

我提交了一个项目，但成绩册中没有显示我已提交的信息。为什么？

如果你已按照作业规格说明的指示，使用合适的 slug 执行了 submit50 命令，你的通过状态应该立即发布到你的 成绩册。首先，最好在你的作业上运行 check50 以确保它满足要求。其次，如果这仍然不行，确保你用于登录 CS50.dev 的 GitHub 用户名与你的 成绩册 顶部显示的 GitHub 用户名相同。

如果我提交了一个问题但没有达到 70% 的及格线，我可以重新提交吗？

可以！你可以重新提交；我们只会将你最近的提交计入你的进度。

如果我的 check50 分数不符合预期，可能是什么原因？

你的 check50 分数是准确的。运行 check50 后，会提供一个 URL 链接到你的结果。请注意，check50 会查找是否精确满足检查要求。因此，如果它期望在输出后有换行符而不存在这样的换行符，该检查将显示为未通过。在某些情况下，期望输出和实际输出在 check50 结果中可能看起来完全相同。在这种情况下，最好考虑空格和其他不可见字符可能导致的问题。当然，也有可能你误解了作业的某一部分，需要重新阅读问题集规格说明。

如果我的代码风格分数不符合预期，可能是什么原因？

你的代码风格分数将基于你提交中每个源代码文件的 style50 结果。当你运行 submit50 时，确保你的文件夹只包含该问题集必需的文件。如果其中有任何额外的测试文件，它们也会被计入你的分数。从文件夹中删除额外的文件，然后重新提交以获得更新后的 Style 分数。

为什么我没有通过我的最终项目？

提交你的最终项目后，你可以在你的 成绩册 中查看你的提交，了解关于你的得分和未通过的详情。

最终项目未能获得及格分数的最常见原因是你没有遵循 最终项目规格说明。

最终项目未获得及格分数的第二个常见原因与你的文档有关（你最终项目的 README 或 DESIGN 文件）。当你的 README 或 DESIGN 文档未满足规定的要求时，你将不能通过最终项目。文档文件应该相当全面。没有完成包括大量段落在内的全面文档文件的学生将无法获得及格分数。强烈建议你创建一个全面的文档文件，包括 最终项目规格说明 中提到的具体节。此外，请注意 最终项目规格说明 包含了对你的文档的大致字数要求。遵循这些规范将确保你的文档文件包含你通过所需的所有细节。

获取你的证书

如何获取我的免费 CS50 证书？

一旦你完成了这门课程并满足所有要求（如上所述），你将在你的 成绩册 页面上看到一个链接，允许你申请免费的 CS50 证书，类似于 此处显示 的证书。这个链接将在你收到最后一项必需作业的分数，并且你的 成绩册 中的进度条显示课程完成后大约四个小时内可用。一旦这个链接出现，你应该使用你的 GitHub 凭据登录。如果你在访问时遇到问题，请尝试退出 GitHub 并重新登录，然后重新访问该链接下载你的证书。请务必在 1 月 1 日 之前 申请你的证书。

如何从 edX 获取我的认证证书？

每三周一次，CS50 的工作人员向 edX 提供一份满足本课程要求（在所有必需问题上至少获得 70% 分数）的学生名单。通常在此之后的一周内，edX 会生成学生的认证证书（针对已激活验证的学生），届时它们应该会自动出现在 edX 的 控制面板 上。因此，在你满足本课程要求后，edX 最多可能需要 30 天来生成你的认证证书。请注意，edX 不会 通知你，所以请务必定期查看你的控制面板。

如果你满足所有要求已 超过 30 天，并且尽管整个时间段内拥有有效的验证状态但仍然没有收到证书，请发送邮件至 certificate@cs50.harvard.edu 并提供你的详细信息。请不要提前发送邮件；我们不接受加快处理认证证书的请求。

可以加快 edX 颁发我的认证证书吗？

No.

为什么 30 天后我还没有收到认证证书？

首先，请记住，你的认证 edX 证书将在满足三个标准后 30 天内由 edX 颁发：(a) 你的 成绩册 显示你已完成所有必需作业，每项作业至少获得 70% 或更高的分数；(b) 你已向 edX 付款并完成了他们的验证过程，在你的 edX 控制面板上获得了验证徽章；(c) 你已将自己的 成绩册 链接到你的 edX 账户。因此，你应该确保上述三个条件都已满足后已过去 30 天。

其次，只有当你将你的 成绩册 链接到 edX 时，我们才能通知 edX 你的及格状态。访问你的 成绩册，确保页面顶部没有出现金色栏提示你必须将你的 成绩册 链接到你的 edX 账户。如果你看到这样的金色栏，完成链接过程。然后，重新阅读上面关于你何时可以收到证书的时间安排。

最后，如果你仍然没有收到你的 edX 证书，最好确保你的 成绩册 顶部显示的 edX 用户名与你的 edX 控制面板 顶部显示的 edX 用户名相同。如果这些用户名之间存在不匹配，你将需要通知 edX 他们需要将你的验证付款转移到正确的用户名，因为我们可能已经通知他们你的 成绩册 顶部显示的 edX 用户名已通过本课程。

我的证书上会显示什么名字？

免费证书将包含你申领证书时提供的名字。在申领过程中，你将亲自输入你希望显示在证书上的名字。确保你输入你希望显示在证书上的名字！

通过 edX 提供的认证证书将包含与你的 edX 账户关联的名字。

我可以更改我证书上的名字吗？

不可以，我们无法更改你证书上的名字。因为我们依赖你正确输入名字，并且由于与我们合作的学生数量巨大，我们无法提供名字更改服务。欢迎你升级到认证证书，并通过发送邮件至 info@edX.org 与 edX 沟通关于你的认证 edX 证书上显示什么名字。

你们提供印刷版证书吗？

不提供。最好将你的数字证书带到当地的打印店进行打印。
