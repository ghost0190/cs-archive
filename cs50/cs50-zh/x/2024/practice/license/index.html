许可协议

Learning Goals

  • Practice working with files and file 指针
  • 更多 work with strings and arrays
  • Debugging with debug50
  • Use valgrind to check for 内存 leaks

背景

Suppose you work for a company that develops AI-enhanced 许可协议 plate recognition technology. As you develop your technology, you可能想要 to use actual 许可协议 plate numbers as 测试数据. You have a text file with some plate numbers you want to analyze, so you first try reading from that text file and printing out the 许可协议 plates, to test your file-reading logic. But when you run your program, only the last number prints 8 times! What went wrong?

演示

入门

  1. Log into cs50.dev using your GitHub account.
  2. Click inside the terminal window and execute cd.
  3. Execute wget https://cdn.cs50.net/2022/fall/实验s/4/license.zip followed by Enter in order to 下载 a zip called license.zip in your codespace. Take care not to overlook the space between wget and the following URL, or any other character for that matter!
  4. Now execute unzip license.zip to create 的文件夹中名为 license.
  5. You 不再 need the ZIP file, so you can execute rm license.zip and respond with “y” followed by Enter at the prompt.

实现细节

If you 打开 the plates.txt file, you’ll notice that there are actually 8 different 许可协议 plate numbers. There are a few errors in the 分发代码 that are causing this to happen. Let’s start by walking through the code.

We first check for 命令行参数s, since argv[1] should be the text file that contains the 许可协议 plates. We then 创建一个 character array of length 7, since the plate numbers are 6 chars long and we need to save space 的 NUL terminator. Now we 创建一个n array of char *’s (character 指针, otherwise known as strings!) to store the 8 plate numbers. We 创建一个 file pointer to our external text file, 创建一个 variable to hold the index of each array element, and begin reading the file and saving the plate numbers to the array. Finally, to test that we did this correctly, we print out the values in the array.

However, when we compile and execute this code, something is clearly wrong. You’ll need to make the appropriate corrections!

Debugging

Take a 关闭 look at what values are actually being added to the array. You can experiment with debug50找到 error in the 分发代码.

  • 提示
    • What exactly does the variable buffer hold that’s being assigned to each element of the plates array?
    • 笔记 that the plates array as an array of char *’s or string 指针.
    • So when we assign the char array buffer to a char *, what actually happens?

Is there a better way to copy 许可协议 plate numbers to the license array?

  • 更多 提示
    • Would strcpy come in useful here?
    • If you copy data to a pointer, where will that data go?
    • Is malloc 必需 here?
