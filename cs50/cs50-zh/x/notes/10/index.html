回顾

  • 在过去的十周里，你一直在使用所谓的"消防水管"进行学习。
  • 在 这门课程 中，你学会了用多种不同的语言编程；事实上，我们最大的希望是你在所有这些语言中都学会了如何编程，无论是什么语言。
  • 回想我们在过去十周中讨论的各种主题：你已经走了这么远，获得了如此多的技能。
  • 你应该将你的成功衡量为你在 这门课程 开始时的技能与现在 这门课程 结束时的技能之间的差值。
  • 此外，我们希望你在所有其他方面学会了如何解决问题，即如何获取输入，通过算法处理它，并产生一些输出。为此，我们玩了一个游戏，通过口头指令画了一幅画。
  • 注意一些口头指令是更高层次的，而其他指令是更低层次的，就像 这门课程 中使用不同的编程语言一样。
  • 注意一些指令比其他指令更具体。回想那些你不得不精炼代码以完全按你想要的方式执行的时候。
  • 此外，注意一些指令是如何被抽象化的，比如画手臂。这类似于我们如何将代码抽象成函数。
  • 纵观 这门课程 的所有周，你收集了工具并培养了技能。但最重要的是，你学会了如何自学并利用学习资源。

最终项目

  • 你的最终项目是你利用这些技能构建一个项目的机会，这个项目由你自己规定规格和设计。我们希望你加入我们的 CS50 黑客马拉松，这是一个史诗般的通宵活动，我们一起完成最终项目。
  • 此外，你应在最终项目规格说明中注意到利用基于 AI 的工具的机会（在课程本身的任何问题集中都不允许使用这些工具）。
  • 对于在校的同学，我们希望你参加 CS50 展览会来展示你的最终项目。

展望未来

  • 当你在课程学习之后走向 CS50 之外的世界时，你可能需要采取一些步骤来准备和探索。
  • 继续前行，下载并学习关于 VS Code。Cursor 和 Windsurf 是其他流行的文本编辑器。
  • 为了能够在终端上执行命令，就像你在 CS50.dev 上所做的那样，在你的 Mac 或 PC 上安装命令行工具。
  • 了解更多关于 Git 的知识。
  • 使用 GitHub 托管网站。
  • 如果适用，使用 AWS、Azure、Google Cloud、Cloudflare、Heroku 或 Vercel 托管 Web 应用。
  • 在相关的在线社区中提问。
  • 使用基于 AI 的工具提问，如 ChatGPT、Claude、Gemini、GitHub Copilot、Codex 或 v0。
  • 参加我们的任何其他 CS50 课程。
  • 加入我们的众多 社区 之一。

感谢！

  • 感谢你参与 这门课程！
  • 许多人使 这门课程 成为可能：感谢你们让 这门课程 成为可能，感谢你们如此出色的支持！

总结

在这节课中，我们回顾了你在 这门课程 中的学习历程。具体来说，我们鼓励你…

  • 用你在 这门课程 中学到的编程技能来解决世界各地的实际问题。
  • 运用你在 这门课程 中获得的新技能，继续你的学习！
  • 强势收官，提交你的最终项目。
  • Quack!
