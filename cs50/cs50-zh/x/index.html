欢迎

这是 CS50，哈佛大学对计算机科学智力事业与编程艺术的入门课程，面向主修与非主修学生，无论是否有编程经验均可参加。（三分之二的 CS50 学生此前从未学过计算机科学。）这门课程教你如何解决问题，无论是否借助代码，强调正确性、设计与风格。主题包括计算思维、抽象、算法、数据结构以及更广泛的计算机科学。问题集灵感来自艺术、人文、社会科学和自然科学。这门课程不仅教你如何用一门语言编程，更教你如何从根本上编程以及最终如何自学新语言。课程从一门传统但无处不在的语言 C 开始，它奠定了当今新语言的基础，通过它你不仅会学到函数、变量、条件、循环等知识，还会了解计算机内部如何运作，包括内存等。然后课程过渡到 Python，一门更高级的语言，因为有了 C 的基础你会理解得更深入。课程后期会介绍 SQL，通过它你可以将数据存储在数据库中，随后是 HTML、CSS 和 JavaScript，通过它们你可以创建 Web 和移动应用。课程以最终项目作为总结。

如何学习这门课程

即使你不是哈佛的学生，也欢迎通过此开放课件免费"选修"这门课程，按照课程十一周的周次材料逐步学习。每周按照以下流程学习：

📺 观看讲座 — 推荐 → 📖 观看小节 — 推荐 → 🎬 观看短片
↘ ↘
📝 提交问题集

然后提交课程的最终项目。

要提交课程的问题集和最终项目以获得反馈，请先创建一个 edX 账号（如果你还没有的话）。在学习过程中可以通过课程的社区提问！

  • 如果你对来自 edX 的认证证书感兴趣，请在 cs50.edx.org 注册。
  • 如果你对来自 edX 的专业证书感兴趣：
    • Web 开发方向，请在 cs50.edx.org/programs/web 注册。
    • 人工智能方向，请在 cs50.edx.org/programs/ai 注册。
    • Python 编程方向，请在 cs50.edx.org/programs/python 注册。
  • 如果你对来自哈佛继续教育学院的学分转换与认证感兴趣，请在 web.dce.harvard.edu/extension/csci/e/50 注册。
  • 如果你对来自哈佛暑期学校的学分转换与认证感兴趣，请在 web.dce.harvard.edu/summer/csci/s/50 注册。

如何教授这门课程

如果你是一名教师，欢迎根据许可协议采用或改编这些材料用于你自己的课程。此外，我们鼓励教师参加CS50 教育工作坊，了解更多关于 CS50 的课程体系、技术和教学方法。
