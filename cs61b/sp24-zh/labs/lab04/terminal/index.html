如何使用终端

终端指南

以下是CS61B你需要知道的最重要的命令：

cd ：切换工作目录 

  cd hw

此命令会将你的目录更改为 hw 。

pwd ：显示当前工作目录 

  pwd

如果你不确定自己在哪里，此命令会告诉你当前目录的完整绝对路径。

速记命令

  • ~ ：主目录的简写

  • . ：当前目录的简写 

    cd .

    此命令会将你的目录更改为当前目录（也就是什么都不做）。

  • .. ：当前目录上一级父目录的简写 

    cd ..

    此命令会将你的目录更改到其父目录。如果你在 /workspace/day1/ ，此命令会把你放到 /workspace/ 。

ls ：列出目录中的文件/文件夹 

  ls

此命令会列出当前目录中的所有文件和文件夹。你也可以使用 ls <directory> 来列出不同目录的内容——试试 ls .. ！

mkdir ：创建目录 

  mkdir [dirname]

此命令将在当前目录中创建一个名为 dirname 的新目录。你可以把目录想象成在本地计算机上创建另一个文件夹。

touch ：创建新文件 

  touch [filename]

此命令将在当前目录中创建一个名为 filename 的文件。要创建文本文件，你需要运行命令 touch filename.txt 。

rm ：删除文件 

  rm [file]

此命令将从当前目录中删除 file 。如果 file 不存在，则该命令将无法执行。 

  rm -r [dir]

此命令将递归删除 dir 目录。换句话说，它将删除 dir 中的所有文件和目录，以及 dir 本身。使用此命令时请小心！

cat ：显示文件内容 

  cat [file]

此命令可用于在终端中查看文件内容，而无需在程序中打开它们。对于大文件（可能会使终端混乱）或非文本文件（可能会输出乱码），它的用处不大。

cp ：复制文件 

  cp lab1/original lab2/duplicate

此命令将复制 lab1 目录中的 original 文件，并在 lab2 目录中创建一个 duplicate 文件。

mv ：移动或重命名文件 

  mv lab1/original lab2/original

此命令将 original 从 lab1 移动到 lab2 。与 cp 不同，mv不会将原始文件保留在 lab1 目录中。 

  mv lab1/original lab1/newname

此命令不会移动文件，而是将文件从 original 重命名为 newname 。

以下是使用终端时的一些其他有用技巧。

  • 你的shell可以使用 tab补全 来自动补全文件名和目录名。当你有一个不完整的名称（对于已经存在的内容），尝试按 tab 键进行自动补全或显示可能的名称列表。
  • 你可以在终端中复制粘贴。在Mac上这很简单，但在Windows上，需要右键单击来复制和粘贴高亮文本。
  • 如果你想运行最近使用过的命令，按键盘上的 up 方向键直到看到正确的指令。如果你走得太远，使用 down 键返回。如果你正在执行重复的指令，这可以节省输入时间。
  • 你可以同时打开多个终端——如果你运行需要终端的独立任务，这可能有助于加快工作流程。
