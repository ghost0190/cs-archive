如何使用终端

终端指南

以下是您在 CS61B 中需要掌握的最重要的命令：

cd ：更改工作目录 

  cd hw

此命令将把您的工作目录更改为 hw 。

pwd ：打印工作目录 

  pwd

如果您不确定自己在哪里，此命令将告诉您当前所在目录的完整绝对路径。

快捷命令

  • ~ ：主目录的简写

  • . ：当前目录的简写 

    cd .

    此命令将把您的目录更改到当前目录（也就是什么都不做）。

  • .. ：当前目录上一级父目录的简写 

    cd ..

    此命令将把您的目录更改到其父目录。如果您当前在 /workspace/day1/ ，此命令将把您放到 /workspace/ 。

ls ：列出目录中的文件/文件夹 

  ls

此命令将列出当前目录中的所有文件和文件夹。您也可以使用 ls <directory> 来列出不同目录的内容——试试 ls .. ！

mkdir ：创建一个目录 

  mkdir [dirname]

此命令将在当前目录中创建一个名为 dirname 的新目录。您可以将目录视为在本地电脑上创建另一个文件夹。

touch ：创建一个新文件 

  touch [filename]

此命令将在当前目录中创建一个名为 filename 的文件。要创建文本文件，您可以运行命令 touch filename.txt 。

rm ：删除文件 

  rm [file]

此命令将从当前目录中删除 file 。如果 file 不存在，则此命令将不起作用。 

  rm -r [dir]

此命令将递归删除 dir 目录。换句话说，除了 dir 本身，它还将删除 dir 中的所有文件和目录。使用此命令时请小心！

cat ：显示文件内容 

  cat [file]

此命令对于在终端中检查文件内容而不必在程序中打开它们非常有用。对于大文件（可能会使终端杂乱）或非文本文件（可能会输出乱码），它不太有用。

cp ：复制文件 

  cp lab1/original lab2/duplicate

此命令将复制 lab1 目录中的 original 文件，并在 lab2 目录中创建一个 duplicate 文件。

mv ：移动或重命名文件 

  mv lab1/original lab2/original

此命令将 original 从 lab1 移动到 lab2 。与 cp 不同，mv 不会在 lab1 目录中保留原件。 

  mv lab1/original lab1/newname

此命令并不是移动文件，而是将其从 original 重命名为 newname 。

以下是使用终端时一些其他有用的技巧。

  • 你的shell可以用 tab补全 来自动补全文件名和目录名。当你的名称不完整（对于已经存在的东西）时，尝试按 tab 键来自动补全或查看可能的名称列表。
  • 你可以在终端中复制粘贴。在Mac上这很简单，但在Windows上，需要右键单击来复制和粘贴高亮文本。
  • 如果你想运行最近使用过的命令，按键盘上的 向上 箭头键直到看到正确的指令。如果你走得太远了，使用 向下 键往回走。如果你正在执行重复的指令，这可以节省打字时间。
  • 你可以同时打开多个终端——如果你运行的任务需要终端，这可能有助于加快你的工作流程。
