常见问题

面向学生的设置常见问题文档

请查看 设置常见问题文档 以获取更多设置帮助！

我找不到 IntelliJ 的插件！

您可能安装的是 ultimate 版本而不是 community 版本。请确保您安装的是 community 版本！

当我尝试推送时，出现错误"failed to push some refs"

如果您看到提示说"Updates were rejected because the tip of your current branch was behind its remote counterpart"，请阅读 Git WTFS 的这一部分 。

我为 GitHub 设置了 SSH，但出现错误"连接超时"

SSH 只能在安全的（密码保护的）网络上工作。如果您连接到 CalVisitor 或其他不安全的网络，尝试与 GitHub 通信的 git 命令将失败。

要解决此问题，请连接到 eduroam 或安全的 WiFi 网络。

有些学生在克隆个人仓库时遇到"密码验证支持已被移除…"的问题。

如果使用 https 克隆不起作用，请尝试使用 ssh 进行克隆： 

git clone git@github.com:Berkeley-CS61B-Student/sp24-s***.git

curl: (35) schannel: next InitializeSecurityContext failed: Unknown 错误 (0x80092012) - The revocation function was unable to check revocation for the certificate.

将 --ssl-no-revoke 标志添加到 curl 命令（例如，如果命令之前是 curl https://www.google.com ， 请将其更改为 curl --ssl-no-revoke https://www.google.com ）。

警告：远程主机标识已更改

在错误信息的底部，应该会显示 Host key for [something] has changed... 。如果 something 是 github.com 或任何教学机器，请继续按照本指南操作。否则，请在 Ed 上提出私人问题。

要修复此错误，请运行 ssh-keygen -R [something] ，并将 [something] 替换为错误消息中包含的内容。 这通常意味着远程计算机已更改其主机密钥。如果您不信任该计算机，请验证新的主机密钥是否正确 （GitHub 主机密钥可在 此处 获得）。

在 Gradescope 上，我缺少必需的文件

首先，确保您已推送代码！您可以通过在 GitHub 上查看您的仓库来检查。

其次，预期的文件结构是： 

sp24-***
└── lab01
    ├── src
    │   └── Arithmetic.java
    └── tests
        └── ArithmeticTest.java

请注意，文件位于 lab01 目录内。如果文件不在 lab01 内，则自动评分器将无法找到它们。

如果您确定已正确完成上述操作，则您可能有两个 sp24-s* 文件夹的副本（位于您电脑上的不同位置）。请确保终端中的位置和 IntelliJ 中的位置一致，否则您的更改将不会被记录！您可以通过运行 pwd 来查看终端的当前工作目录。

我使用的是 Mac，出现"无法加载 Java 运行时环境"的错误

运行 brew reinstall java ，然后找到以 sudo ln 开头的命令， 就在"为了让系统包装器能找到这个 JDK…"的下方。复制并粘贴运行该命令。

之后，您新安装的 Java 应该会出现在 IntelliJ 中。

在 IntelliJ 中，当我打开 Arithmetic.java 时，顶部的 import 语句是灰色的。

在某些情况下，您可能会看到这样的内容：

IntelliJ 可能会很奇怪——如果您已经确保您的 library-sp24 存在（导航到 File –> 项目 Structure –> Libraries 检查）， 那么请尝试删除该库，重新导入，然后点击"Apply"。请确保在退出窗口之前点击"确定"。
