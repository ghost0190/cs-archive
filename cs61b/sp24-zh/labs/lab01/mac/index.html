Mac 操作系统

A. 环境搭建

  1. 通过在终端中运行此命令来安装 Xcode Command Line Tools（它应该在 macOS 上已经可用——尝试使用搜索功能/Finder 找到它）： 

    xcode-select --install

    这可能需要一段时间。如果您使用的是较旧的系统，可能需要更新软件。如果您遇到关于可用空间不足的错误，请仔细检查您还剩多少可用空间（所需空间的粗略估计是至少 40GB 的可用空间）。您可能还需要重启笔记本电脑。

    还有一个 StackOverflow 帖子，您可以参考 此处 ，如果 问题是类似的。 但是，如果您遇到困难，请来找工作人员帮助您！

  2. 此时，使用以下命令验证 git 是否已安装： 

     git --version

    如果此命令返回有效版本号且未失败，则您已成功安装 git。如果安装正常， 请跳过本指南的其余部分并返回实验。

B. Git 安装问题

如果您在安装 Git 时遇到问题，请尝试此 链接 中的"在 macOS 上安装"说明。 如果仍然有问题，请联系您的 TA。
