常见问题

我在 Windows 笔记本电脑上，保存测试不工作。

如果你使用的是 Windows 系统，换行符的表示方式与 Mac 和 Linux 略有不同。我们已经更新了骨架代码来修复由此可能产生的问题。你可以运行 git pull skeleton main 来获取新的更改。

我在自动评分器上测试 1.4 和 1.6 失败了。

从错误消息中可能很难确定问题所在。为了解决这个问题，尝试编写或修改一个测试来保存、加载，然后再次保存（无论测试是否通过都没关系），然后手动打开 src/save.txt 来检查输出，看看它与你的预期有何不同。

确保你使用的是 [x][y] 坐标，其中 (0, 0) 是棋盘的左下角！在这种坐标体系下，当保存到文件和从文件加载时，方块的方向应该保持不变。

确保你确实在 loadBoard 中修改了 GameOfLife 对象的方块和尺寸。

需要注意的一些常见问题是，确保你在 loadBoard 中从文件中读取了宽度和高度，并设置了实例变量，以便 width 和 height 被正确初始化。 此外，由于左下角是 (0, 0)，请记住当你重新加载棋盘时，你可能是从上到下读取文件的，因此在"填充"棋盘时要确保方向正确读取（当你将文件拆分为数组时，棋盘的顶行首先作为第一行读取，底行最后读取，因此在将其加载回棋盘时，请确保顶行对应棋盘的顶行）。
