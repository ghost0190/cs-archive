Go

你将在 Go 中完成所有实验。Go 的网站包含大量教程信息。你应该使用 Go 1.22 或任何更新的版本。 你可以通过运行 go version 来检查你的 Go 版本。

我们建议你在自己的机器上完成实验，这样你可以使用你已经熟悉的工具和文本编辑器等。许多编辑器都有 Go 的插件，例如 VS Code 的 Go 扩展。一些商业 IDE 如 GoLand 提供免费教育授权。我们很乐意通过 Piazza 和答疑时间提供支持，帮助你配置 Go。实验可能无法在 Athena 上运行。

macOS

你可以使用 Homebrew 来安装 Go。安装 Homebrew 后，运行 brew install go。

Linux

根据你的 Linux 发行版，你可能可以从包仓库获取最新版本的 Go，例如运行 apt install golang。否则，你可以从 Go 的网站手动安装二进制文件。首先，确保你运行的是 64 位内核（uname -a 应该显示 "x86_64 GNU/Linux"），然后运行： 

$ wget -qO- https://go.dev/dl/go1.23.5.linux-amd64.tar.gz | sudo tar xz -C /usr/local
你需要确保 /usr/local/go/bin 在你的 PATH 中。你可以通过将 export PATH=$PATH:/usr/local/go/bin 添加到 shell 的初始化文件（通常是 .bashrc、.bash_profile 或 .zshrc 之一）来实现。

Windows

实验可以在 Microsoft 的 WSL2（Windows Subsystem for Linux，第 2 版）下运行。

要使用 WSL 2，首先确保你已安装 Windows Subsystem for Linux。然后从 Microsoft Store 添加 Ubuntu 24.04。之后你应该能够启动 Ubuntu Linux。然后你可以按照上面 Linux 的说明操作。

确保你运行的是 WSL 第 2 版。WSL 1 无法运行实验。要检查，在 Windows 终端中运行 wsl -l -v 以确认已安装 WSL 2 和正确的 Ubuntu 版本。
