Xv6，一个简单的类Unix教学操作系统

简介

Xv6是一个于2006年夏季开发的教学操作系统， 我们为新的本科课程6.S081将xv6移植到了RISC-V。

Xv6源代码与文档

最新的xv6源代码和文档可通过以下方式获取 
git clone git://github.com/mit-pdos/xv6-riscv.git
和 
git clone git://github.com/mit-pdos/xv6-riscv-book.git

Unix第六版

xv6的灵感来源于Unix V6以及：

  • Lions的Commentary on UNIX' 6th Edition，John Lions，Peer to Peer Communications；ISBN：1-57398-013-7；第1版（2000年6月14日）。
    • Lions 注释的在线版本，以及源代码。
    • v6源代码也可通过The Unix Heritage Society在线上获取。
以下内容有助于阅读原始代码：
  • The PDP11/40 Processor Handbook，Digital Equipment Corporation，1972。
    • 一个PDF（由扫描图像制作， 不可文字搜索）
    • 一个按指令名称索引的网页版 本。
