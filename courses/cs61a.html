Berkeley CS61A

计算机程序的构造与解释

CS61A 用 Python、Scheme 和 SQL 讲解抽象、递归、高阶函数、解释器和程序设计思想，是 Berkeley CS 入门序列中极具代表性的核心课程。

SP26 英文版
Level入门
SchoolUC Berkeley
TopicsPython / Scheme / SQL
Sourcecs61a.org

Learning Path

从 Python 语法进入程序抽象。

建议以官方日历为主线，把讲座、教材阅读、实验、作业和项目连在一起推进；不要只看视频或只刷题。

函数与递归

先用 Python 熟悉表达式、控制流、递归和高阶函数。

抽象与解释

通过 Scheme 和解释器理解语言如何表达计算。

数据与查询

用数据抽象、对象和 SQL 连接程序与信息结构。
