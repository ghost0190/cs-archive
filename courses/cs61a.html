Berkeley CS61A

计算机程序的构造与解释

Learning Path

用抽象组织程序。

这门课适合在语法之外理解函数、递归、数据抽象和解释器。

函数与递归

先用 Python 熟悉表达式、控制流、递归和高阶函数。

抽象与解释

通过 Scheme 和解释器理解语言如何表达计算。

数据与查询

用数据抽象、对象和 SQL 连接程序与信息结构。
