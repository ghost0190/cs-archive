Learning Path

建议按“概念、练习、项目”推进。

CS50x 的强度来自连续实践。不要只看讲座，最好把每周 problem set 当成主线。

先建立编程直觉

从 Scratch 到 C，关注变量、条件、循环、函数和内存模型。

再进入数据与算法

排序、查找、哈希表、树和复杂度会把“能写代码”推到“理解代码”。

最后做完整作品

Python、SQL 和 Web 部分适合连接成一个可展示的最终项目。

课程档案 / 01

一门覆盖面很广、强调动手实践的计算机科学起点。

CS50x 不要求学习者已经会编程。课程用连续的问题集把算法、内存、数据结构和 Web 开发串成一条完整主线，适合希望建立整体认识，而不是只学习某一种语言的人。

适合人群

第一次正式学习计算机科学

适合零基础学习者、需要补齐底层概念的开发者，以及希望用一个完整项目检验学习成果的人。

  • 无需编程先修
  • 需要稳定投入时间完成问题集
  • 建议准备基本的命令行和文件操作能力
学习方式

问题集是课程主体

讲座负责建立概念，真正的理解来自调试代码和完成项目。遇到困难时应先缩小问题范围，再查看提示，而不是直接复制答案。

  • 每周完成讲座、实验和问题集
  • 记录常见错误及调试过程
  • 最终项目应独立完成并可公开展示

内容地图

阶段 01计算与 C 语言

Scratch、变量、控制流、函数、数组、指针和内存模型。

阶段 02算法与数据结构

搜索、排序、复杂度、链表、哈希表和树。

阶段 03Python、SQL 与 Web

从低层编程切换到应用开发，理解数据库和客户端—服务器模型。

完成标准

能够独立拆解问题、实现程序并完成一个可展示项目。

学完后不要求熟练掌握所有语言，但应理解算法、内存、数据和 Web 应用之间的关系，并能使用调试工具定位常见错误。
